# 기성 준비·제출·수금 사용법

## 쌓인 자료를 한 번에 넣기

**문서함 → 기성 자료 넣기**에서 시작합니다. 문서 편집과 기성 관리 권한을 가진 관리자가 사용합니다.

1. **현장 · 프로젝트**를 선택합니다. 기성 공정이 등록된 계약이 하나면 자동 선택됩니다. 여러 개면 연결할 계약을 고릅니다.
2. **파일 선택** 또는 **폴더 선택**을 누릅니다. 영수증, 입고내역서, 작업 사진, 문서를 구분하지 않고 함께 넣습니다. 한 번에 최대 1,000개이며 파일당 한도는 화면에 표시됩니다. ZIP 압축은 풀고 선택합니다.
3. **업로드**를 누릅니다. 이때는 원본만 저장합니다. 업로드 중에는 창을 닫지 마세요. 실패한 파일은 다시 업로드할 수 있으며 이미 저장한 파일은 다시 보내지 않습니다.
4. **처리 시작**을 누릅니다. 이후 창을 닫거나 컴퓨터를 꺼도 서버가 순서대로 분석합니다. 업로드하지 못한 파일이 있으면 저장된 파일 수를 따로 표시합니다.
5. 나중에 **지난 접수 · 이어서 보기**에서 진행 상황을 확인합니다. **확인 필요만**을 선택해 불명확한 문서와 공정 연결을 검토합니다.

사진 원본은 보관하고, 가능한 큰 사진은 용량을 줄인 별도 사본으로 분석·미리보기합니다. 원본 다운로드는 처음 올린 파일입니다. 수기 메모는 인쇄 내용과 구분해 기록하며 판독이 불명확하거나 금액이 다르면 확인 대상으로 남깁니다. 자동 분석이 모든 필기와 문서를 정확히 읽는다는 뜻은 아닙니다.

문서 상세에서 원본을 보고 **정보 수정 → 원본과 추출 내용을 대조했습니다**를 체크합니다. 확인 사유가 있는 문서는 확인 메모를 적어야 검토 완료됩니다. 메모는 검토 이력으로 보존되며 원본이나 인쇄 금액을 덮어쓰지 않습니다. 이어서 접수 화면의 **공정 다시 연결** 또는 **기성 증빙 보기**에서 연결 결과를 확인합니다.

기성 공정이 아직 없으면 먼저 자료를 보관할 수 있습니다. 공정을 등록한 뒤 지난 접수를 열어 계약을 선택하고 **공정 연결**을 누릅니다. 이미 지정한 계약을 다른 계약으로 자동 변경하지 않습니다.

같은 범위에 동일한 파일이 있으면 기존 자료를 사용합니다. 파일 내용이 다른 유사 영수증은 확인 대상으로 남을 수 있습니다. 이 접수는 기성 증빙을 모으는 기능이며, 경비 승인·지급·시공 완료 수량·청구 금액을 자동 확정하지 않습니다. 입고 증빙을 기성으로 인정할지는 계약의 청구조건에 따릅니다.

## 처음 한 번: 계약의 청구조건 확인
계약 관리에서 수주 계약을 열어 원청과 합의한 청구조건을 입력합니다.
- 근거: 서명 계약 또는 원청 확인 내용을 적습니다.
- 반입 자재 기성 인정: 해당 계약에서 인정하는 경우만 선택합니다.
- 매월 제출일과 며칠 전부터 준비할지 정합니다.
- 최초 1회 / 매 기성 / 최종·유보 해제에 필요한 서류를 각각 입력합니다.
- 확인 저장을 누릅니다. 기존 운영 계약의 금액과 인정 실적은 이 과정에서 자동 변경되지 않습니다.

## 매 회차 처리
1. 현장의 확인된 실적을 기성 근거 대장에서 확인하고 회차를 만듭니다.
2. 회차의 **제출 서류**를 엽니다. 필요한 서류마다 문서함 또는 계약서류함의 원본을 연결합니다.
3. **제출파일 준비**를 누릅니다. 누락·만료·읽을 수 없는 원본이 있으면 먼저 해결합니다.
4. 제출 ZIP을 내려받아 내용을 확인합니다. 파일 준비와 내려받기는 실제 송부가 아닙니다.
5. 원청 이메일·포털로 실제 보낸 후 **송부 기록**에 날짜와 송부처/접수번호를 남깁니다.
6. 원청 회신을 문서함에 올리고 **원청 접수 / 보완 요청 / 원청 수리**에 회신 원본을 연결합니다.
7. 수리 후 실제 승인 금액을 별도로 기록합니다. 입금 시 수금을 회차에 연결하면 미수금이 갱신됩니다.

## 보완과 이력
보완 요청을 받으면 같은 회차에서 서류를 교체하고 새 제출본을 준비합니다.
예전 제출 ZIP은 그대로 남으며 새 파일은 v2, v3 순서로 쌓입니다.
이미 제출한 금액·확인 수량을 소급해서 덮어쓰지 않습니다. 금액 정정은 계약·기성 원장의 정정 절차로 처리합니다.

## 자재 제출물
메일앱이 열리는 것은 메일 초안 작성입니다. 실제 발송으로 표시하지 않습니다.
원청 회신 원본과 실제 결과(승인·조건부승인·반려)를 함께 기록합니다.
조건부승인과 반려는 조건·사유를 입력합니다.

## 첫 화면
기성 준비·제출·수금에서 현장/계약별 다음 할 일, 제출일, 미수금, 유보금을 봅니다.
공사가 끝난 현장도 계약의 미수금·제출 의무를 확인할 수 있습니다.
AI 판독이나 공정 추정치만으로 원청 승인과 청구 인정이 확정되지 않습니다.

## 적용 범위
계약별 요구서류와 제출 이력은 새 흐름을 사용합니다. 기존 승인·청구·입금 기록은 보존합니다.
원청별 엑셀 양식의 자동 채우기는 지원하는 양식에 한하며, 그 외 원청 양식은 작성한 원본을 요구서류로 연결합니다.
원청 포털 자동 전송은 포함하지 않습니다.

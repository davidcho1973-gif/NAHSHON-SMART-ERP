# 현장 등록·출퇴근 운영 안내

## 작업자

현장에 붙인 QR은 한 장만 사용합니다. 휴대폰 기본 카메라로 찍으세요.

- 처음 온 작업자: **처음 온 작업자 등록 → 이름·전화번호 → 본인 PIN 설정 → 출근하기**.
- 연결된 휴대폰: **같은 QR → 본인 이름 확인 → 출근하기 또는 퇴근하기**.
- 새 휴대폰 또는 연결이 풀린 경우: **전화번호와 개인 PIN → 출퇴근 화면**.
- PIN을 잊었거나 기존 직원인데 PIN이 없는 경우: 인사담당자에게 **출퇴근 연결/PIN 재설정 링크**를 요청합니다.
- QR을 찍는 것만으로 기록되지는 않습니다. 출근·퇴근 버튼을 눌러 완료 메시지를 확인합니다.

## 인사담당자

ERP **직원 등록·관리**를 기준 명단으로 사용합니다.

1. **QR 신규·확인 필요** 직원을 열어 이름·소속 회사·현장·팀·고용 형태를 확인하고 저장합니다.
2. 기존 직원은 **출퇴근 연결**을 눌러 본인에게 PIN 설정 링크를 전달합니다. 작업자 계정이 없으면 함께 생성됩니다. 관리자 권한은 생성하지 않습니다.
3. **추가정보·W-9 링크**로 후속 정보를 받습니다. 이 개인 링크는 공개 게시하지 않습니다.
4. **현장 공용 QR**을 인쇄해 출입구에 붙입니다. 등록과 출퇴근용 종이를 따로 붙이지 않습니다.

신규 작업자는 인사 확인 전에도 출퇴근 기록을 남길 수 있습니다. 인사 확인이 끝나지 않은 직원이 포함된 급여대장은 확정·지급할 수 없습니다. 출퇴근 기록과 기존 급여자료는 삭제하지 않습니다.

## 전환 시 주의

기존 등록 QR 주소도 같은 출퇴근 화면으로 연결됩니다. 예전 이름 선택/전화번호 끝 네 자리 방식으로 연결한 기기는 본인 확인을 한 번 다시 해야 합니다. 전화번호가 중복 등록된 직원은 인사담당자가 먼저 명단을 정리해야 합니다. 번호만 입력해서 기존 직원 기록이나 소속을 바꿀 수는 없습니다.

반장은 인사 등록·PIN 발급 권한이 없습니다. 기존 팀 인력 조회와 업무 보고 기능을 사용합니다.

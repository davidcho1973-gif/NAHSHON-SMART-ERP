# 현장 QR 등록·출퇴근·공지 안내

## 작업자

- 처음: 현장 QR → 처음 온 작업자 등록 → 이름·전체 전화번호 → 등록 → 출근 화면 → 출근하기.
- 기존 직원: 현장 QR → 전화번호 뒤 4자리 → 본인 이름 → 출근하기 또는 퇴근하기.
- 기억된 휴대폰: 같은 현장 QR → 본인 이름과 버튼 확인 → 출근 또는 퇴근.
- 현장 QR에는 PIN 입력 단계가 없습니다. 이름·번호가 겹치거나 바뀌면 인사담당자에게 요청하고 중복 등록하지 않습니다.

버튼을 누르고 서버 저장이 성공하면 “출근하였습니다.” 또는 “퇴근하였습니다.”와 시간이 표시됩니다. 같은 화면에 반대 버튼은 나타나지 않습니다. 다음 출퇴근 때 QR을 다시 엽니다.

공지가 없으면 “이 화면을 닫으셔도 됩니다”로 끝납니다. 브라우저 창을 강제로 닫지는 않습니다.
공지가 있으면 짧은 내용이 보이고 “자세히 보기 · 첨부파일”을 펼칠 수 있습니다. 필수 공지는 “내용을 확인했습니다”를 각각 누르고 마지막에 “확인하고 닫기”를 누릅니다. 일반 공지도 확인하고 닫으면 다시 표시되지 않습니다. 공지 내용이 수정되면 다시 표시됩니다.

공지 오류는 출퇴근 저장을 취소하지 않습니다. 다시 시도하거나 담당자에게 알리고 창을 닫을 수 있습니다. 반대로 출퇴근 저장 자체가 실패하면 오류 안내를 보고 재시도합니다. 반복해서 출퇴근 버튼을 누르지 말고 마지막 기록을 확인하세요.

## 관리자: 공지 올리기

ERP/개인앱 메시지에서 해당 현장 공지방을 엽니다. 기존 공지 작성 권한을 가진 관리자만 설정할 수 있습니다.

1. 제목·내용을 작성하고 필요하면 사진/파일을 첨부합니다.
2. “출퇴근 공지 설정”을 펼칩니다.
3. 표시: 출근·퇴근 / 출근 / 퇴근을 선택합니다. 기본은 표시 안 함입니다.
4. 필요한 공지만 “필수 확인”을 선택합니다.
5. 게시 종료일을 설정하고 전송합니다. 기본 종료일은 14일 뒤이며 현장 시간대의 당일 끝까지입니다.
6. 같은 설정 안의 “확인 현황”에서 직원별 확인 시각을 봅니다. 보고서 시각은 UTC로 표시됩니다.

현장 공지는 해당 현장 직원에게, 현장 없는 회사 공지는 같은 회사 직원에게만 표시합니다. 팀이 지정된 방은 해당 팀으로 제한합니다. 기간 종료·삭제된 공지는 더 이상 출퇴근에 표시되지 않습니다. 종료 전 중단하려면 원 공지를 삭제합니다. 확인 기록은 읽었다고 누른 사실이며 실제 이해나 안전교육 이수의 증명은 아닙니다.

인사담당자는 직원 회사·현장·팀·고용형태를 확인합니다. 추가정보/W-9은 필요한 직원에게 개인 링크로 전달합니다. 현장 QR과 개인 세금서류 링크를 혼용하지 않습니다.

## 현재 리만 환경

liman.erp.dasolusa.com은 현재 DASOL 환경의 별칭입니다. 이 릴리스는 나손과 DASOL(리만 주소 포함)에 같은 기능을 배포하며, 별도 리만 DB를 생성하지 않습니다. 각 환경의 공지·직원·출퇴근 기록은 각 환경 DB에 저장됩니다.

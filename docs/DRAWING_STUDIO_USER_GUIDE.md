# 도면 스튜디오 사용 안내

공정별 도면의 세부 공정에서 **기성 편집**을 누르면 2D 편집기가 바로 열립니다. 일반 도면 보기에서는 상단의 **CAD 편집**으로 열 수 있습니다.
작도 내용은 현재 PDF의 해당 쪽에 저장됩니다. 별도의 CAD 프로그램은 기존 버튼으로 열며 이 화면에는 3D 모델링이 없습니다.

## 실제 거리와 면적

1. 상단 **축척 맞추기 → 도면에 적힌 치수로 맞추기 (ft)**를 누릅니다. `12′-6½″`처럼 도면에 적힌 **숫자 글자**를 감싸는 사각형의 두 모서리를 찍습니다. PDF 글자가 있으면 바로 읽고, 스캔 이미지이면 선택한 부분만 기존 OCR 서비스로 판독합니다. 이미지와 읽힌 값을 비교해 선택한 뒤, 그 치수에 해당하는 **치수선의 양 끝**을 찍고 **맞추기**를 누릅니다. 숫자를 다시 입력하지 않아도 됩니다. 치수 글자의 폭은 실제 거리의 기준이 아니므로 치수선 양 끝은 따로 지정합니다.
   - `12′-6½″`는 약 `12.541667 ft`, `12.5`는 `12.5 ft`로 읽습니다. 분수 인치를 지원합니다. 판독값이 다르면 적용 전에 고칠 수 있습니다.
   - 글자가 흐리면 **다시 선택**으로 범위를 좁히거나 **직접 입력 (ft)**을 사용합니다. 판독만으로 축척을 저장하지 않으며, 확인하지 않은 값은 적용하지 않습니다.
   - 이미 설정한 축척이나 도면에서 읽은 축척도 다른 치수선으로 한 번 대조합니다. Esc 또는 취소로 언제든 축척 설정을 중단할 수 있습니다.
2. **길이 재기**에서 시작점과 끝점을 누릅니다. **면적 재기**는 모서리를 차례대로 찍고 Enter, **그리기 완료**, 또는 첫 점을 다시 눌러 마칩니다. 점이 부족하거나 경계가 교차하면 이유를 표시하고 입력한 점을 유지합니다. 각도는 세 점을 찍으며 두 번째 점이 꼭짓점입니다.
3. 새 편집의 기본 단위는 **ft**입니다. 도면 치수로 축척을 맞추면 편집기도 ft로 전환됩니다. 오른쪽에서 ft, ft-in, m, mm와 소수 자릿수를 선택할 수 있으며, 저장한 단위 선택은 다음에 열 때 유지됩니다. 확대·축소는 측정값을 바꾸지 않습니다.
4. 정확한 길이로 작도하려면 직선·거리·화살표 하나를 선택하고 **직선 길이 → 선택 도형에 적용**을 누릅니다. ft-in 표시 상태에서 길이 입력은 ft입니다.

축척이 없으면 실제 길이·면적 대신 **축척 필요**가 표시됩니다. 새 측정은 당시 축척을 보관하므로 이후 축척을 바꿔도 기존 수량은 유지됩니다. 다시 계산하려면 도형을 선택하고 **정밀 2D 도구 → 선택 측정에 현재 축척 적용**을 누릅니다. 이전 버전에서 만든 도형은 저장된 개별 축척이 없어 도면 축척을 따릅니다. 스캔의 찌그러짐은 자동 보정하지 않으므로 실제 치수와 대조하세요.

## 측정에서 기성 작성까지

1. 영역을 선택한 뒤 **정밀 2D 도구 → 내부 영역 그려서 공제**로 개구부 등의 모서리를 찍고 Enter를 누릅니다. 외부 경계를 벗어나거나 기존 공제와 겹치는 영역은 적용되지 않습니다. 공제 후 순면적이 표시됩니다.
2. 원하는 도형을 선택하고 **선택 수량을 공정에 가져오기**를 누릅니다. SF·㎡ 등 면적 공정에는 영역, LF·M 등 길이 공정에는 선, EA 등 개수 공정에는 **개수 기호**를 선택합니다. 단위 종류가 맞지 않으면 입력하지 않습니다.
3. 도면 서버 저장을 먼저 마친 뒤, 저장 버전이 적힌 산출 행과 표시 도면 PNG·원본 연결을 기성 초안에 저장합니다. 이미지 업로드가 실패하면 수량을 변경하지 않습니다. 동일 도형을 다시 가져오면 해당 산출 행을 갱신합니다. 이미 있던 직접 입력 수량은 별도 행으로 보관됩니다.
4. **다음: 수량 입력 · 검토 요청**에서 작업일·단계·수량·증빙을 확인하고 검토를 요청합니다. 가져오기만으로 확인 수량이나 기성 금액이 확정되지 않습니다.

## 작도와 편집

- 직선, 연속선, 다각형, 사각형, 타원, 수정구름, 화살표, 문자, 펜, 강조를 제공합니다. 두 점 도형은 두 번 클릭하고, 연속선·다각형은 Enter로 완료합니다. 자유 펜은 누른 채 그립니다.
- 문자는 오른쪽 **문자 / 도형 이름**을 입력하고 도면에 놓습니다. 기존 도형을 선택하면 이름도 붙일 수 있습니다.
- **선택**으로 도형을 누르고 드래그해 이동하거나, 꼭짓점 손잡이를 끌어 바꿉니다. 빈 곳을 드래그하면 영역 안의 도형을 다중 선택합니다. Ctrl+클릭으로 선택을 더하거나 뺍니다.
- 선 색·굵기, 채우기, 불투명도, 점선, 문자 크기를 바꾸고, 복제·삭제·앞뒤 순서·왼쪽 정렬·좌우/상하 반전을 할 수 있습니다. 회전은 직선·연속선·다각형·사각형·화살표·각도·펜에 적용합니다. 회전한 사각형은 다각형으로 보관됩니다. 타원·구름·문자의 회전은 지원하지 않습니다.
- **스냅**은 작도한 도형의 끝점·중점·교차점·선 위, 타원의 중심·사분점에 맞춥니다. Alt를 누르면 일시 해제합니다. 원본 PDF 선의 자동 추적은 포함하지 않습니다.
- **직교**는 선·화살표·연속선 등의 방향을 90도, Shift는 15도 간격으로 맞춥니다. 사각형·타원·수정구름은 두 모서리로 정하므로 직교의 영향을 받지 않습니다. 이 세 도구에서 Shift를 누르면 정사각형·원 비율로 맞춥니다. **격자**는 위치를 보기 위한 보조선입니다.
- **수정구름**은 바깥쪽으로 둥근 원호를 이어 그립니다. 직교 때문에 예전에 납작하게 그려진 도형은 선택한 뒤 모서리 손잡이를 옮겨 높이를 주세요. 기존 위치를 추측해서 바꾸지는 않습니다.
- 레이어마다 이름·표시·잠금을 관리합니다. 잠긴 레이어의 도형은 이동·삭제·속성 변경을 할 수 없습니다. 새 도형은 선택한 레이어에 들어갑니다.
- Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y: 실행 취소·다시 실행, Ctrl+D: 복제, Ctrl+A: 보이는 도형 모두 선택, Delete: 삭제, Esc: 작도 취소·선택 해제.

**정밀 2D 도구**에서는 세 점 호, 조명·스위치·콘센트·문 등 개수 기호, 실제 길이·방향을 입력하는 다음 점 작도, 간격 복사(오프셋), 가로·세로 일정 간격 반복 복사를 제공합니다. 오프셋은 공제가 없는 선·연속선·다각형·사각형에 적용하며, 경계가 무너지는 큰 간격은 거부합니다. 호는 연속선 근사로 저장하므로 정밀한 곡선 제작 데이터는 기존 CAD 도구에서 처리하세요.

그룹을 누르면 함께 선택·이동하고 Alt+클릭으로 개별 도형을 고를 수 있습니다. 선택 도형의 레이어를 옮기거나 다각형·연속선의 꼭짓점을 추가·삭제할 수 있습니다. **2D 반복 부품 · 저장한 화면**에서 선택을 이름 붙여 보관하고 재사용하거나 현재 확대 위치·레이어 표시를 저장합니다. 삽입한 부품은 독립 사본입니다.

## 저장과 이력

완성된 편집은 약 1.2초 후 자동 저장하며 **저장** 또는 Ctrl+S로 바로 저장할 수도 있습니다. **서버 저장 완료 · 버전**을 확인하세요. 그리는 중인 점은 이 기기의 복구본에 보관하고, 완료한 도형을 서버에 저장합니다. **저장하고 닫기**는 미완성 도형이나 저장 실패가 있으면 이동을 막습니다.

**저장 이력 / 작업 보관 → 수정 이력**에서 최근 30개 저장 버전을 볼 수 있습니다. 이전 버전을 선택하면 편집기에 불러오며 새 버전으로 저장합니다. 다른 창의 저장과 충돌하면 덮어쓰기를 막고 현재 편집을 유지합니다. **작업 JSON**으로 보관하고, **파일 · 수량 내보내기 → 작업 JSON 복구**에서 같은 도면의 파일을 검증하여 불러올 수 있습니다. 기기 복구본은 브라우저 저장 공간·정리 설정의 영향을 받으므로 서버 저장 완료 확인이 필요합니다.

**수량표 CSV**는 Excel에서 열 수 있습니다. **표시 SVG·DXF**는 편집한 표시만 내보내며 원본 PDF 선을 변환하지 않습니다. DXF는 현재 도면 축척에 맞춘 피트 좌표로 내보내 공간 배치를 유지합니다. 개별 측정의 보관 축척과 다르면 CSV의 수량을 기준으로 비교하세요. 원본 포함 검토본은 보내기의 PDF·PNG를 사용합니다. 새 PDF 개정판에는 이전 쪽 작도를 자동으로 옮기지 않습니다.

## 옆에서 보내기

1. **보내기**에서 현재 보이는 화면, 전체 도면, 선택 도형 주변 중 첨부 범위를 고릅니다.
2. PNG 또는 PDF를 고르고 **미리보기 만들기**를 누릅니다. 현재 편집·치수·보이는 레이어를 담습니다. PDF는 미리보기와 같은 이미지 기반 검토본입니다.
3. **ERP 메신저**에서는 참여·발송 권한이 있는 방을 고르고 최근 대화를 읽으며 메시지를 작성할 수 있습니다. **메일**은 수신 이메일·제목·본문을 입력합니다.
4. **첨부와 함께 보내기**를 누를 때만 실제 전송합니다. 화면에 보인 미리보기 파일이 첨부됩니다. 도면을 더 고쳤다면 미리보기를 새로 만듭니다.

메일은 기존 ERP 발신 계정과 첨부 한도를 사용합니다. 설정이 없으면 이유를 표시하며 발송 완료로 처리하지 않습니다. 메신저 파일은 방 권한으로 보호되는 저장소에 보관합니다. 전송 결과가 불확실하면 자동 재발송하지 않으므로 보낸 편지함 또는 대화방을 먼저 확인합니다.

**파일 저장**은 첨부 파일을 내려받습니다. **다른 앱 공유**는 기기의 파일 공유 기능이 지원될 때 활성화되며, 설치·지원된 앱에서 전송을 마무리합니다. 별도 메신저의 계정 연결이나 자동 발송을 의미하지 않습니다.

## 운영 메모

- 새 `drawing_studios`, `drawing_studio_revisions`, `drawing_share_dispatches` 테이블은 배포 마이그레이션으로 생성합니다.
- 관리 직책은 공정 `view/edit` 권한을 따릅니다. 전송에는 공정 `export`, ERP 메신저 전송에는 메시지 `edit` 권한도 필요합니다. 소속 현장과 원본 문서 접근 권한을 매번 확인합니다.
- 메신저 첨부는 `document-intelligence.disk`의 비공개 저장소를 사용합니다. 운영 환경은 S3 영구 저장소가 필요합니다. 메일은 기존 `MailReady` 설정과 첨부 한도를 재사용하며 새 외부 서비스 키는 필요하지 않습니다.
- 한 쪽에 최대 2,000개 도형·30개 레이어·30,000개 점을 저장합니다. 원본 PDF와 기존 도면 표시·기성 자료는 별도 기존 흐름으로 유지합니다.

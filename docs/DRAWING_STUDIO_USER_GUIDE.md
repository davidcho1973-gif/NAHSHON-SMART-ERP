# 도면 스튜디오 사용 안내

공정별 도면에서 도면을 크게 연 뒤, 상단의 **CAD 편집** 또는 **보내기**를 누릅니다.
작도 내용은 현재 PDF의 해당 쪽에 저장됩니다. DWG 원본 편집은 이번 범위에 포함하지 않습니다.

## 실제 거리와 면적

1. 상단 **축척 맞추기**에서 이미 아는 치수의 양 끝을 찍고 실제 길이를 입력합니다. 도면에서 읽은 축척을 선택한 경우에도 알고 있는 치수로 한 번 확인합니다.
2. **CAD 편집 → 거리**에서 시작점과 끝점을 누릅니다. **면적**은 모서리를 차례대로 찍고 Enter 또는 **완료**로 마칩니다. 각도는 세 점을 찍으며 두 번째 점이 꼭짓점입니다.
3. 오른쪽에서 mm, m, ft, ft-in과 소수 자릿수를 선택합니다. 확대·축소는 측정값을 바꾸지 않습니다.
4. 정확한 길이로 작도하려면 직선·거리·화살표 하나를 선택하고 **직선 길이 → 선택 도형에 적용**을 누릅니다. ft-in 표시 상태에서 길이 입력은 ft입니다.

축척이 없으면 실제 길이·면적 대신 **축척 필요**가 표시됩니다. 스캔의 찌그러짐이나 한 장 안의 서로 다른 축척은 자동 보정하지 않습니다. 한 쪽에 한 축척을 적용하므로 같은 축척의 영역에서 측정합니다.

## 작도와 편집

- 직선, 연속선, 다각형, 사각형, 타원, 수정구름, 화살표, 문자, 펜, 강조를 제공합니다. 두 점 도형은 두 번 클릭하고, 연속선·다각형은 Enter로 완료합니다. 자유 펜은 누른 채 그립니다.
- 문자는 오른쪽 **문자 / 도형 이름**을 입력하고 도면에 놓습니다. 기존 도형을 선택하면 이름도 붙일 수 있습니다.
- **선택**으로 도형을 누르고 드래그해 이동하거나, 꼭짓점 손잡이를 끌어 바꿉니다. 빈 곳을 드래그하면 영역 안의 도형을 다중 선택합니다. Ctrl+클릭으로 선택을 더하거나 뺍니다.
- 선 색·굵기, 채우기, 불투명도, 점선, 문자 크기를 바꾸고, 복제·삭제·앞뒤 순서·왼쪽 정렬을 할 수 있습니다. 회전은 직선·연속선·다각형·화살표·각도·펜에 적용합니다. 사각형·타원·구름·문자의 회전은 지원하지 않습니다.
- **스냅**은 작도한 도형의 끝점·중점·선 위, 타원의 중심·사분점에 맞춥니다. Alt를 누르면 일시 해제합니다. 원본 PDF 선의 자동 추적은 포함하지 않습니다.
- **직교**는 90도, Shift는 15도 간격으로 작도 방향을 맞춥니다. **격자**는 위치를 보기 위한 보조선입니다.
- 레이어마다 이름·표시·잠금을 관리합니다. 잠긴 레이어의 도형은 이동·삭제·속성 변경을 할 수 없습니다. 새 도형은 선택한 레이어에 들어갑니다.
- Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y: 실행 취소·다시 실행, Ctrl+D: 복제, Ctrl+A: 보이는 도형 모두 선택, Delete: 삭제, Esc: 작도 취소·선택 해제.

## 저장과 이력

**저장** 또는 Ctrl+S로 서버에 저장합니다. 자동 저장은 아닙니다. 저장하지 않은 내용이 있으면 닫을 때 확인합니다.

**저장 이력 / 작업 보관 → 수정 이력**에서 최근 30개 저장 버전을 볼 수 있습니다. 이전 버전을 선택하면 편집기에 불러오며, 저장하면 새 버전으로 기록합니다. 다른 창의 저장과 충돌하면 덮어쓰기를 막고 현재 편집을 유지합니다. **작업 JSON**으로 로컬 보관한 뒤 최신 도면을 다시 여세요. JSON은 보관·지원용이며 이번 버전에는 가져오기 기능이 없습니다.

새 PDF 개정판에는 이전 쪽의 작도를 자동으로 옮기지 않습니다. 거리·면적과 주석은 도면 검토 자료이며 기성 수량이나 승인 값을 자동으로 바꾸지 않습니다.

## 옆에서 보내기

1. **보내기**에서 현재 보이는 화면, 전체 도면, 선택 도형 주변 중 첨부 범위를 고릅니다.
2. PNG 또는 PDF를 고르고 **미리보기 만들기**를 누릅니다. 현재 편집·치수·보이는 레이어를 담습니다. PDF는 미리보기와 같은 이미지 기반 검토본입니다.
3. **ERP 메신저**에서는 참여·발송 권한이 있는 방을 고르고 최근 대화를 읽으며 메시지를 작성할 수 있습니다. **메일**은 수신 이메일·제목·본문을 입력합니다.
4. **첨부와 함께 보내기**를 누를 때만 실제 전송합니다. 화면에 보인 미리보기 파일이 첨부됩니다. 도면을 더 고쳤다면 미리보기를 새로 만듭니다.

메일은 기존 ERP 발신 계정과 첨부 한도를 사용합니다. 설정이 없으면 이유를 표시하며 발송 완료로 처리하지 않습니다. 메신저 파일은 방 권한으로 보호되는 저장소에 보관합니다. 전송 결과가 불확실하면 자동 재발송하지 않으므로 보낸 편지함 또는 대화방을 먼저 확인합니다.

**파일 저장**은 첨부 파일을 내려받습니다. **다른 앱 공유**는 기기의 파일 공유 기능이 지원될 때 활성화되며, 설치·지원된 앱에서 전송을 마무리합니다. 별도 메신저의 계정 연결이나 자동 발송을 의미하지 않습니다.

## 운영 메모

- 새 `drawing_studios`, `drawing_studio_revisions`, `drawing_share_dispatches` 테이블은 배포 마이그레이션으로 생성합니다.
- 관리 직책은 공정 `view/edit` 권한을 따릅니다. 전송에는 공정 `export`, ERP 메신저 전송에는 메시지 `edit` 권한도 필요합니다. 소속 현장과 원본 문서 접근 권한을 매번 확인합니다.
- 메신저 첨부는 `document-intelligence.disk`의 비공개 저장소를 사용합니다. 운영 환경은 S3 영구 저장소가 필요합니다. 메일은 기존 `MailReady` 설정과 첨부 한도를 재사용하며 새 외부 서비스 키는 필요하지 않습니다.
- 한 쪽에 최대 2,000개 도형·30개 레이어·30,000개 점을 저장합니다. 원본 PDF와 기존 도면 표시·기성 자료는 별도 기존 흐름으로 유지합니다.

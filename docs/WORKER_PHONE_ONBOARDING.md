# 인사 전용 작업자 등록 및 앱 연결

## 확정 운영 방식

- 인사 권한자(hr_manager 및 기존 인사 권한을 가진 admin/super_admin)만 직원 등록·승인·반려·개인 앱 연결 QR 발급을 처리한다.
- 반장은 자기 팀의 등록 상태를 조회만 한다. 승인, 확인 버튼, 의견 작성, QR 발급은 없다.
- 팀 공용 가입 QR과 공개 이름/전화 가입 경로는 제거했다. 예전 /join 주소도 로그인 및 인사 권한이 필요하다.

## 사용 순서

1. 인사담당자가 ERP 직원 등록·관리 → 인사 · 작업자 등록 또는 /worker-onboarding을 연다.
2. 이름, 전화번호, 소속을 입력하고 저장한다. 미국 번호는 10자리, 해외 번호는 +국가번호 포함. 이메일과 SMS는 필요 없다.
3. 인사담당자가 신원·소속을 확인하고 인사 승인한다. 신규 직원은 기존 employees/users에 시급 작업자, 본인 범위로 연결된다. 반장 확인을 기다리는 단계는 없다.
4. 인사담당자가 직원 개인용 앱 연결 QR을 발급해 본인에게 전달한다. 15분 유효·1회 사용이며 재발급 시 이전 링크는 무효다.
5. 직원은 본인 휴대폰으로 스캔하여 4자리 PIN을 설정한다. 반복/연속 숫자와 전화번호 끝 4자리는 허용하지 않는다. 기존 출퇴근 앱에 로그인된다.
6. 이후 로그인 상태를 유지한다. 기기 교체나 분실은 인사담당자의 기존 PIN 재설정 절차로 처리한다.

개인 앱 연결 QR과 현장 출퇴근 QR은 다르다. 기존 출퇴근의 현장 확인 조건은 유지한다. 시급은 인사·급여 담당자가 별도로 입력하며 자동 추정하지 않는다.

## 접근과 데이터 보호

반장은 실제 팀 반장 배정, 사용자 팀 범위, 직원 팀·회사·현장이 일치하는 경우에만 자기 팀을 조회한다. 인사담당자는 부여받은 범위에서 새 등록을 관리한다. 팀 목록은 공용 QR 배포 대상이 아니라 인사담당자가 지정하는 소속이다.

동일 번호의 기존 직원은 이름·소속·활성 시급자 조건이 일치하고 PIN 미설정일 때만 기존 사번에 연결한다. 다른 팀·중복 번호·기존 PIN·관리 계정은 자동 덮어쓰지 않는다. 기등록 직원 삭제 대신 정지·퇴사 상태로 관리한다.

등록 이력은 worker_enrollments, 직원/계정은 기존 employees/users, 활성화는 기존 auth_setup_tokens/login_devices, 출퇴근은 기존 attendance_logs를 사용한다. users.email nullable로 가짜 이메일 없이 처리한다. 승인 전에는 직원 로그인 계정이 만들어지지 않는다.

## 검증

권한 검사는 화면과 서버 양쪽에서 적용한다. 테스트는 반장의 등록·승인·반려·발급 차단, 타 팀 비공개, 일반 직원/현장소장 차단, 인사 범위, 예전 공개 등록 주소 차단, 중복 신원, 토큰 만료/재사용, PIN 로그인 및 실제 출퇴근 저장을 포함한다.

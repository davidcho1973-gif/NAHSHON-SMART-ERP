# 신규 직원 · 기존 직원 관리자 초대

수퍼관리자는 이메일을 미리 받거나 직원 정보를 대신 입력하지 않고 새 입사자에게 링크 하나를 전달할 수 있습니다.

## 새 입사자

1. 정식 Google 또는 ERP 비밀번호로 로그인한 수퍼관리자가 **계정 · 권한 관리 → 신규 관리자 초대**를 누릅니다.
2. **현장관리자** 또는 **관리자**를 선택하고 관리 범위를 지정합니다. 관리자는 전체 현장 권한이며, 담당 현장만 맡길 때는 현장관리자를 선택합니다. 현장·회사 선택은 신규 직원의 소속 정보에도 반영됩니다. 초대 메모는 선택이며 이름·이메일을 미리 받을 필요가 없습니다.
3. **초대 링크 · QR 만들기 → 카톡에 보낼 내용 복사**로 직원 한 명에게 전달합니다. 같은 자리에서는 QR을 보여 줍니다. 카톡 자동 발송은 아닙니다.
4. 직원이 같은 링크에서 **이름·전화번호**를 입력하고, **Google** 또는 **이메일·새 ERP 비밀번호**로 등록을 완료합니다. Gmail이 아니어도 됩니다. 이름·전화번호 입력 후 로그인 등록은 15분 안에 마칩니다.
5. 완료 시 직원 정보와 계정이 함께 생성되고 지정한 권한으로 ERP·개인앱을 사용할 수 있습니다. 완료 화면에서 개인앱과 설치 안내로 이동합니다. 별도의 현장 작업자 등록이나 두 번째 초대 링크는 필요 없습니다.

등록 완료 전에는 직원·계정이 생성되지 않습니다. 신규 직원은 관리직으로 등록하며 시급·급여·구매 권한은 자동 부여하지 않습니다. 입사 서류·급여 조건은 인사담당자가 기존 직원 관리에서 설정합니다.

**등록 대기 중인 신규 관리자 초대** 목록에서 취소하거나 재발급할 수 있습니다. 재발급 시 이전 링크는 취소됩니다. 만료된 미완료 초대도 목록에서 재발급할 수 있습니다. 사용 완료한 초대는 재사용할 수 없습니다.

## 이미 등록한 작업자

**계정 · 권한 관리**에서 이메일·Google·ERP 비밀번호가 없는 활성 작업자/반장의 **관리자로 초대**를 누릅니다. 역할·관리 범위를 정하고 링크·QR을 전달합니다. 직원은 기존 등록 전화번호 전체를 입력하고 로그인 정보를 설정합니다. 기존 계정에 권한이 적용되며 직원·출퇴근·급여 기록 연결을 유지합니다.

신규 링크에 이미 등록된 전화번호나 로그인 이메일을 입력하면 중복 등록을 막습니다. 기존 직원은 위의 기존 직원 초대를 사용합니다. 이미 로그인 정보가 있는 계정은 계정 수정에서 관리합니다.

## 링크와 로그인

초대는 **7일·1회용**입니다. 링크는 지정한 직원 한 명에게만 전달합니다. 전화번호 입력·대조는 SMS 인증이 아닙니다. 초대 취소·만료·사용 완료·발급자 권한 해제 시 등록할 수 없습니다. 직원이 역할·관리 범위를 바꿀 수 없습니다.

리만은 다솔 ERP의 별칭입니다. 리만에서 만든 초대도 정식 다솔 주소에서 열려 Google 등록이 같은 주소로 이어집니다. 카톡 링크는 Chrome 또는 Safari에서 열어 Google 등록을 진행하고 앱 설치 안내를 따릅니다.

등록 완료 후 접속은 정상 Google/ERP 비밀번호 로그인입니다. 이 QR은 최초 입사 등록 초대이며, 구형 관리자 개인 QR 자동 로그인과 다릅니다. 현장 출퇴근 QR은 계속 유지됩니다.

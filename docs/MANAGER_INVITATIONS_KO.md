# 기존 작업자 관리자 초대

정식 Google 또는 비밀번호로 로그인한 수퍼관리자가 **계정 · 권한 관리**에서 이메일·로그인 정보가 없는 활성 작업자/반장의 **관리자로 초대**를 누릅니다.

1. 역할과 담당 범위를 선택합니다. 관리자는 전체 현장, 현장관리자는 지정 현장·회사·전체 범위를 선택합니다. 구매 권한은 초대에 포함되지 않으며 기존 구매 권한 설정에서 별도로 부여합니다.
2. 초대 링크·QR을 생성합니다. ‘카톡에 보낼 내용 복사’를 눌러 해당 직원과의 카톡 대화에 붙여넣거나, 휴대폰의 공유하기를 사용합니다. 같은 자리에서는 QR을 보여줍니다. 자동 카톡 발송 기능이 아닙니다.
3. 직원은 개인 초대를 열고 기존에 등록한 전화번호 전체를 입력합니다. 미국 번호는 국가번호 1 생략을 허용합니다. 이는 등록 번호 대조이며 SMS 인증이 아닙니다. 링크·QR은 해당 직원에게만 전달합니다.
4. Google 계정으로 등록하거나, 사용할 이메일과 새 ERP 비밀번호(문자·숫자 포함 10자 이상)를 입력합니다. 이메일 자체가 없는 직원은 이메일을 먼저 마련해야 합니다.
5. 완료 즉시 기존 계정에 권한과 로그인 정보가 반영됩니다. 기존 직원·출퇴근·급여 기록의 연결은 유지됩니다. 완료 화면에서 ERP, 개인앱, 설치 안내로 이동합니다.

초대는 7일 유효·1회용입니다. 전화번호 확인 후 등록 단계는 15분 안에 완료합니다. 재발급은 이전 초대를 취소합니다. 취소·만료·사용 완료·직원 계정 정보 변경·발급자 권한 해제 시 기존 초대는 사용할 수 없습니다. 등록 완료 전까지 작업자 권한이 유지됩니다. 이미 이메일/Google/ERP 비밀번호가 있는 계정은 초대로 덮어쓰지 않고 계정 수정에서 관리합니다.

구형 ‘관리자 개인 QR 자동 로그인’과 다른 기능입니다. 이번 QR은 최초 등록을 위한 개인 초대이며, 등록 후 접속은 정상 Google/ERP 비밀번호 로그인입니다. 현장 출퇴근 QR은 계속 유지됩니다.

# CAD 2D 이동 도구

기존 CAD의 정밀 편집에서 사용하는 Windows 기준 조작입니다. SketchUp의 이동 조작을 XY 평면에 맞췄습니다. 면 돌출, Z축 이동, 자동접기 등 3D 동작은 포함하지 않습니다.

| 작업 | 조작 |
| --- | --- |
| 이동 | 객체 선택 → `M` → 기준점 클릭 → 목적점 클릭. 기준점에서 드래그한 뒤 놓아도 됩니다. |
| 이동 복사 | `M`에서 `Ctrl` 한 번 → 기준점 → 목적점. 이동 중에도 `Ctrl`로 복사를 전환합니다. |
| 연속복사 | 첫 기준점을 잡기 전에 `Ctrl` 두 번 → 기준점 → 놓을 위치들을 차례로 클릭 → `Esc`. |
| 반복 배열 | 일반 복사본 하나를 놓은 직후 `5x` 또는 `*5` 입력 → `Enter`. 원본 외에 같은 간격으로 5개가 생깁니다. |
| 등분 배열 | 일반 복사본을 마지막 위치에 놓은 뒤 `4/` 또는 `/4` 입력 → `Enter`. 원본과 마지막 복사본 사이를 4구간으로 나눕니다. |
| 배열 수정 | 다른 편집을 시작하기 전 `3x`, `6/` 또는 새 거리를 입력합니다. 이전 배열 전체를 한 번에 수정하고 한 번의 실행 취소로 되돌립니다. |
| 정확한 거리 | 마우스로 방향을 정한 뒤 `500mm`, `2ft`, `-100mm` 등 입력 → `Enter`. 완료 직후에도 거리를 수정할 수 있습니다. |
| 좌표 | `[100mm,50mm]`는 도면 절대좌표, `<100mm,50mm>`는 기준점에서의 상대변위입니다. 세 번째 좌표를 쓰면 0이어야 합니다. |
| 방향 잠금 | `→` X축, `←` Y축. 같은 키로 해제합니다. `Shift`를 누르고 있는 동안 현재 이동 방향을 유지합니다. |
| 평행·직각 | 참조 선 위에 마우스를 올린 뒤 `↓` 한 번은 평행, 두 번은 직각, 세 번은 해제입니다. |
| 취소 / 선택 | `Esc`는 진행 중인 이동을 취소합니다. `Space`는 선택 도구입니다. |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y`. 아직 배치하지 않은 미리보기가 있으면 먼저 그 작업만 취소합니다. |

입력칸을 직접 클릭하거나 캔버스에서 숫자를 입력하면 됩니다. 단위 없는 값은 현재 표시 단위를 따릅니다. `100mm<30`처럼 거리와 각도도 지정할 수 있습니다.

## 선 늘이기와 그룹

- 아무것도 선택하지 않은 상태에서 `M`으로 선의 끝점을 잡으면 그 점만 움직이며 연결된 선의 끝점도 함께 따라옵니다. 폴리선의 선분을 잡으면 해당 선분의 두 끝점이 움직입니다.
- 선을 미리 선택한 뒤 이동하면 선 전체가 이동하고, 같은 그룹·높이에서 연결된 다른 선은 연결을 유지하도록 늘어납니다. 선택한 선을 부분 수정하려면 우클릭의 **선 늘이기**를 사용합니다.
- 그룹과 블록은 전체가 함께 움직입니다. 서로 닿아 있는 독립 그룹은 연결되지 않습니다. 그룹 내부를 늘이려면 우클릭 **그룹 편집** 또는 선택 도구에서 더블클릭 후 작업합니다. 선택 도구에서 `Esc`로 그룹 편집을 끝냅니다.
- 그룹의 사각 기준점은 `Alt`로 모서리 → 변 중점 → 중심을 전환합니다. 빨간 십자 손잡이를 잡으면 평면 회전하며 각도를 입력할 수 있습니다.
- 그룹/블록의 우클릭 **연결점 추가**에서 위치와 방향을 차례로 지정합니다. 이동할 때 연결점을 잡아 다른 연결점에 놓으면 위치와 방향을 맞춥니다. 연결점은 저장·다시 열기와 DWG 변환에 유지됩니다.

## 우클릭과 저장

선택 상태의 우클릭에는 이동·이동 복사·연속복사·선 늘이기·그룹 편집·연결점 명령이 있습니다. 이동 중에는 기준점을 유지하면서 복사 전환, 방향 고정, 평행·직각, 취소를 선택합니다. 복사 직후에는 반복/등분 배열 입력 메뉴가 나타납니다.

기존 **저장** 버튼으로 개정본을 저장합니다. 잠긴 객체나 지원하지 않는 원본 형상이 섞이면 전체 작업을 거부합니다. 배열은 복사 500개, 추가 객체 50,000개까지이며, 2D 그룹은 공유 컴포넌트 정의가 아닌 독립 선택 그룹입니다. 이 메뉴에는 CAD 전용 명령도 있으므로 SketchUp의 3D 상황별 메뉴 전체와 동일하지는 않습니다.

# 직원등록과 개인앱 설치

## 처음 온 작업자

1. 휴대폰 기본 카메라로 현장 QR을 찍습니다.
2. **처음 온 작업자 등록**을 누릅니다.
3. 본인 **이름과 전화번호**를 입력합니다. 현장은 QR에 따라 표시됩니다.
4. **입력 확인**을 누르고 이름·번호를 확인합니다. 틀렸으면 **수정하기**를 누릅니다.
5. **등록 완료 → 개인앱 열고 설치 → 홈 화면에 추가** 순서로 누릅니다.
6. 화면을 닫고 새로 생긴 **내 출퇴근** 아이콘을 눌러 본인 이름이 나오는지 확인합니다.

등록만으로 출근 기록이 생기지는 않습니다. 출근할 때는 현장 QR을 찍고 **출근하기**를 눌러 완료 안내를 확인합니다.

현장 운영회사 표시가 직원의 고용회사를 확정하는 것은 아닙니다. 소속·고용구분 및 추가 인사서류는 인사담당자가 확인합니다. W-9 등 추가서류는 담당자가 안내하는 경우에 작성합니다.

## 휴대폰별 설치

- **안드로이드 Chrome:** 앱의 설치 버튼을 누릅니다. 설치 창이 없으면 브라우저의 **⋮ → 앱 설치 / 홈 화면에 추가**를 사용합니다.
- **아이폰:** 개인앱 화면의 **공유 → 홈 화면에 추가 → 추가**를 누릅니다. 해당 메뉴가 없으면 Safari에서 개인앱을 엽니다.
- **삼성 인터넷:** 개인앱 화면의 **메뉴 → 현재 페이지 추가 → 홈 화면**을 사용합니다.
- **카카오톡 안에서 열린 경우:** 먼저 **다른 브라우저로 열기**로 옮긴 다음 개인앱에서 설치합니다.

설치 안내서나 가입 초대 링크를 바로가기로 저장하지 말고, 반드시 **개인앱 열고 설치** 버튼을 통해 개인앱 화면으로 이동합니다.

## 다음에 들어올 때

홈 화면 아이콘을 누르면 같은 개인앱 주소가 열립니다. 저장된 로그인이 유효하면 바로 들어갑니다. 로그인이 풀렸다면 다시 등록하지 마세요.

- 작업자는 기존 안내대로 등록한 전화번호 뒷 4자리로 본인 이름을 찾습니다.
- 이메일·Google 계정이 있는 직원은 **이메일 · Google로 내 앱 열기**를 이용할 수 있습니다.
- 본인 이름이 아니면 출퇴근을 누르지 말고 연결을 해제한 뒤 본인으로 들어갑니다.

등록 QR이나 초대 링크를 다시 열어도 기존 직원 계정을 새로 만드는 용도로 사용하지 않습니다. 사용이 끝난 초대 링크는 정상 로그인으로 안내되며, 초대만으로 관리자 권한이 다시 부여되지 않습니다.

# 직원등록 · 출퇴근 · 관리직원 개인앱

일반 작업자는 현장 QR로 출퇴근합니다. 개인앱은 관리직원과 작업반장이 사용합니다.

| 구분 | 처음 이용할 때 | 매일 이용할 때 |
|---|---|---|
| 일반 작업자 | 현장 QR → 이름·전화번호 → 내용 확인 → 등록 완료 | 같은 현장 QR → 본인 이름 확인 → 출근 또는 퇴근 → 완료·공지 확인 |
| 관리직원·반장 | 수퍼관리자가 계정·역할 지정 → 본인 로그인 → 개인앱 설치 | 홈 화면의 개인앱 아이콘 → 허용된 업무 사용 |

## 일반 작업자: 앱 설치가 필요 없습니다

1. 본인 휴대폰 기본 카메라로 출입구의 **현장 QR**을 찍습니다.
2. **처음 온 작업자 등록**을 누릅니다.
3. **이름과 전화번호**를 입력합니다. 현장은 QR에 따라 표시됩니다.
4. **입력 확인**을 누르고 이름·번호가 맞으면 **등록 완료**를 누릅니다.
5. **출퇴근 화면 열기 → 본인 이름 확인 → 출근하기**를 누릅니다.
6. **출근하였습니다**와 시각을 확인합니다. 공지가 있으면 읽고 화면을 닫습니다.

퇴근할 때도 같은 QR을 찍고 **퇴근하기**를 누릅니다. 등록하거나 QR을 찍는 것만으로 출퇴근이 기록되지는 않습니다.

같은 브라우저에 연결 정보가 남아 있으면 다음부터 본인을 알아봅니다. 브라우저가 달라지거나 정보가 지워졌다면 현장 QR에서 전화번호 뒷 4자리와 본인 이름으로 들어갑니다. 이름이 없거나 번호가 바뀌었다면 인사담당자에게 확인합니다. **이미 등록한 사람은 다시 등록하지 않습니다.**

일반 작업자에게 이메일·비밀번호·PIN 설정이나 앱 설치를 요구하지 않습니다. 현장 운영회사는 직원의 고용회사를 확정하는 값이 아닙니다. 소속·고용구분 및 추가 인사서류는 인사담당자가 확인합니다. W-9 등 추가서류는 담당자가 안내하는 경우에 작성합니다.

## 관리직원·반장: 본인 계정으로 로그인한 뒤 설치합니다

1. 수퍼관리자가 ERP의 **계정·권한 관리 → 신규 관리자 초대**에서 직책과 담당 범위를 지정합니다. 반장은 **작업반장**과 담당 팀을 선택합니다. 직원이 가입 화면에서 스스로 권한을 선택할 수는 없습니다.
2. 직원은 전달받은 초대에서 이름·전화번호와 Google 또는 새 비밀번호를 등록합니다. 이미 현장 QR로 등록한 작업자라면 기존 계정 행의 **관리자로 초대**를 사용합니다. 이때 역할·이메일을 먼저 수정하지 마세요. 초대를 완료하면 기존 직원 기록에 로그인 정보와 지정한 직책이 연결됩니다.
3. [관리직원·반장 로그인](https://erp.nahshonmep.com/login?app=1)에서 등록된 이메일·비밀번호 또는 연결된 Google 계정으로 로그인합니다.
4. [개인앱 열고 설치](https://erp.nahshonmep.com/attendance-app?install=1)를 누르고 홈 화면에 추가합니다.
5. 앱을 닫고 새 아이콘을 다시 눌러 **본인 이름**과 업무 화면을 확인합니다.

반장은 부여받은 팀 업무를, 관리직원은 부여받은 업무를 사용합니다. 앱 설치가 구매·인사·ERP 전체 권한을 추가로 주지는 않습니다. 구매요청과 구매처리 권한도 기존 설정을 따릅니다.

초대를 이미 완료한 사람은 일반 로그인으로 들어갑니다. 초대 링크를 다시 쓰거나 직원등록을 반복하지 않습니다. 관리자가 이메일만 입력해 직접 만든 계정에는 본인 비밀번호가 아직 없습니다. 이 경우 같은 이메일의 Google 계정으로 먼저 로그인한 뒤, 개인앱 **나 → 이메일 비밀번호 설정**에서 정할 수 있습니다. 해당 Google 계정도 사용할 수 없다면 로그인 설정을 담당자에게 확인해야 합니다.

## 휴대폰별 설치

- **안드로이드 Chrome:** 앱의 설치 버튼을 누릅니다. 설치 창이 없으면 **⋮ → 앱 설치 / 홈 화면에 추가**를 사용합니다.
- **아이폰:** 개인앱 화면에서 **공유 → 홈 화면에 추가 → 추가**를 누릅니다. 해당 메뉴가 없으면 Safari에서 개인앱을 엽니다.
- **삼성 인터넷:** 개인앱 화면에서 **메뉴 → 현재 페이지 추가 → 홈 화면**을 사용합니다.
- **카카오톡 안에서 열린 경우:** 먼저 **다른 브라우저로 열기**로 옮긴 후 로그인하고 개인앱에서 설치합니다.

가입 초대장이나 설치 설명 페이지를 아이콘으로 저장하지 말고 **로그인한 개인앱 화면에서 설치**하세요. 외부 브라우저로 옮기면 로그인을 한 번 더 요구할 수 있습니다.

## 다음에 아이콘으로 들어올 때

관리직원·반장의 정상 개인앱 아이콘은 항상 같은 주소 `/attendance-app`을 엽니다. 저장된 로그인이 유효하면 바로 들어가며, 로그인이 풀렸으면 본인 계정으로 다시 로그인합니다. 사용이 끝난 초대 링크는 일반 로그인으로 안내합니다. 만료된 초대장을 다시 활성화하거나 새 계정을 만들지 않습니다.

일반 작업자가 예전에 만든 개인앱 아이콘을 누르면 현장 QR 출퇴근 안내가 나옵니다. 현장이 확인되면 **출퇴근 화면 열기**를 이용할 수 있고, 그렇지 않으면 현장의 QR을 다시 찍습니다. 기존 출퇴근·영수증 자료를 삭제하거나 재등록하는 절차가 아닙니다.

휴대폰에 이미 저장된 바로가기 주소 자체를 서버가 바꿀 수는 없습니다. 예전 아이콘이 계속 잘못된 주소를 열면 정상 개인앱에서 새 아이콘을 추가하고 재접속을 확인한 다음 예전 아이콘을 지웁니다. 일반 작업자는 앱 아이콘 대신 현장 QR을 사용하면 됩니다.

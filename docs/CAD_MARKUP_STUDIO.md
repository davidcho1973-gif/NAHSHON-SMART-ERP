# 도면 위 표시

CAD 화면의 기본 작업 모드다. 원본 객체를 선택하거나 고치지 않고 별도의 표시를 작성한다. 기존 선·문자·치수·레이어 편집은 **CAD 정밀 편집** 모드에서 사용한다.

## 사용

- **닫힌 경계 색칠**: 원본의 닫힌 직선 폴리선 내부를 클릭하면 그 경계를 그대로 복사한 표시를 만든다. 경계가 겹치면 가장 작은 영역을 선택한다. 개별 선으로 그린 방, 곡선 폴리선, 해치 등은 추정하지 않고 자유 영역으로 지정하도록 안내한다.
- **자유 영역**: 경계를 순서대로 클릭하고 첫 점을 다시 클릭하거나 Enter로 완성한다. 교차하는 경계는 거부한다. **사각 영역**은 대각선 드래그로 만든다.
- 영역의 색, 불투명도, 사선/교차 해치를 속성 패널에서 수정한다. 선택한 꼭짓점을 드래그하면 경계를 고칠 수 있다. 방 내부 자동 인식 기능은 포함하지 않는다.
- **변경 구름**: 변경 부분을 감싸도록 드래그한다. 구름은 실제 곡선이며 크기를 바꾸어도 균일한 물결 간격을 다시 계산한다.
- **연결 메모**: 지시할 위치에서 메모 위치까지 드래그하고 내용을 입력한다. 양쪽 손잡이로 지시점과 메모 위치를 각각 조절한다. 더블클릭 또는 내용 수정 버튼으로 다시 입력한다.
- **자유 펜 / 형광펜**: 누른 채 그린다. **번호 / 기호**는 클릭하여 연속 번호를 놓고 내용 수정에서 기호로 바꿀 수 있다.
- Shift 추가 선택, 드래그 이동, 방향키 미세 이동(Shift는 10배), Ctrl+D 복사, Delete 삭제, Ctrl+Z/Y 실행 취소/다시 실행을 지원한다. 표시 목록으로 겹친 항목을 고르고, 앞뒤 순서와 잠금을 바꿀 수 있다.
- Esc는 진행 중인 표시를 취소한다. Space+드래그 또는 가운데 버튼으로 화면을 이동하고 휠로 확대한다. 새 표시와 꼭짓점 조절에 원본 끝점/중점/중심 스냅을 사용할 수 있다.
- **내 도구함**은 색·불투명도·두께·무늬를 최대 12개까지 이 브라우저의 localStorage에 저장한다. 도면 데이터는 localStorage에 저장하지 않는다.

## 보존과 출력

`cad_drawing_revisions.markups`의 nullable JSON에 원본 좌표계로 표시를 저장한다. DXF와 동일한 개정 번호/트랜잭션/부모 행 잠금/409 충돌 보호/현장 권한을 적용한다. 이전 버전 클라이언트가 markups를 생략하면 직전 개정의 표시를 보존하고, 명시적인 빈 배열만 전체 삭제로 처리한다. 표시만 바꾼 저장은 받은 DXF 문자열을 그대로 재사용한다. 업로드 원본 파일은 기존의 별도 비공개 파일로 유지한다.

저장은 수동이며 저장되지 않은 변경과 진행 중인 표시가 있으면 페이지 이탈 시 확인한다. 409 발생 시 현재 편집을 유지하며 자동 덮어쓰기는 하지 않는다. 도면 변경 이력 및 기성에 고정한 개정 화면은 당시 표시를 읽기 전용으로 재현한다. 기존 기성 증빙 아카이브의 CAD 파일은 여전히 DXF만 포함한다.

**현재 화면 인쇄 / PDF**는 화면 범위를 흰 바탕의 3배 해상도 이미지로 출력한다. 표시 보기 체크를 끈 경우에도 출력에는 표시를 포함한다. 현재 개정, 저장 전 작업 여부, 축척 인쇄가 아니라는 설명을 넣는다. 문서 내보내기 권한이 있어야 이 기능을 사용할 수 있다. 전체 보기 후 출력하면 도면과 표시를 함께 맞출 수 있다.

**CAD만 DXF / DWG**에는 표시가 포함되지 않는다. PDF는 원본 CAD의 모든 객체를 해석하는 대체 엔진이 아니며, 기존 뷰어의 미지원 객체는 출력에서도 누락될 수 있다. 화면에 미지원/읽기 전용 객체 수와 호환성 안내를 유지한다. 정확한 축척 출력, DWG에 표시 객체 병합, 자동 영역 인식, 표시를 포함한 기성 아카이브는 이번 범위에 포함하지 않는다.

## 검증 및 제한

표시 종류와 모든 필드는 서버 허용 목록으로 검사한다. 최대 1,000개 표시, 전체 50,000개 점, 개별 2,048개 점, JSON 2MB, 메모 500자를 허용한다. 좌표·색·불투명도·크기 범위를 검증하며 HTML/SVG/실행 명령은 저장 형식에 없다. 구름 곡선은 최대 512개로 제한하고 해치 생성은 화면 범위로 잘라 과도한 확대에서도 작업량을 제한한다.

회귀 검사는 `tests/Feature/CadDrawingTest.php`, `tests/js/cad-markup.test.mjs`, `tests/browser/cad-markup.cjs`에 포함한다. 브라우저 검사는 합성 도면만 사용하여 원본 바이트 보존, 모든 표시 종류, 꼭짓점 수정, 잠금/순서/복사, 실행 취소, 입력 취소, 저장 충돌, 저장 중 조작, 재열기, 읽기 전용, PDF 이미지 준비, 모바일 너비를 확인한다. 기존 CAD 및 기성 연결 검사도 함께 유지한다.

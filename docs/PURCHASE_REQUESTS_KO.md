# 구매신청 사용 설명서

2026.10.05

## 한 번 연결하고, 필요한 물건을 요청하세요

### 누가 무엇을 하나요?

요청자는 개인앱에서 필요한 자재를 올립니다. 구매 담당자는 ERP에서 확인하고 구매·배송·입고 상태를 처리합니다. 수퍼관리자는 사용할 관리자에게 권한을 부여합니다.

### 수퍼관리자

구매신청과 구매처리를 기본으로 사용할 수 있습니다. Google 또는 이메일·비밀번호로 로그인해 개인앱을 사용합니다. ERP 구매처리는 이메일·비밀번호 또는 Google로 정식 로그인해야 합니다.

### 구매신청 권한을 받은 관리자

개인앱에서 새 요청을 보내고 본인 요청의 상태를 확인합니다. 구매완료·보류·품절 처리는 구매 담당자가 합니다.

### 구매처리 권한을 받은 관리자

ERP 구매요청 화면에서 요청을 처리합니다. 개인앱으로 직접 요청도 해야 한다면 구매신청 권한을 함께 부여합니다.

### 가장 짧은 업무 흐름

관리자 권한 지정 → 관리자 로그인 → 개인앱 구매신청 → 구매 담당자 처리 → 요청자 알림 → 실제 입고 확인.

### 이번 화면 문제의 원인

davidcho1973 계정은 슈퍼관리자·전체 현장·활성 상태입니다. 이전에는 별도 구매신청 체크가 없으면 수퍼관리자의 메뉴도 숨겼습니다. 이번 버전은 수퍼관리자에게 구매신청을 기본 제공하도록 통일했습니다.

## 수퍼관리자: 권한을 주고 로그인 안내하기

### 1. 사용할 관리자 선택

ERP → 인원 → 계정·권한에서 기존 관리자 계정을 엽니다. 개인앱 요청만 할 사람은 개인앱 구매신청을 허용합니다. 사무실 구매 담당자는 ERP 구매처리를 허용합니다. 현장·회사 범위도 실제 담당 범위에 맞춥니다.

### 2. 관리자 로그인

관리자 개인 QR 기능은 종료되었습니다. Google 또는 이메일·비밀번호로 로그인한 뒤 개인앱 주소를 엽니다. 기존 QR 링크와 QR 연결 정보는 더 이상 사용할 수 없습니다. 현장 출퇴근 QR은 그대로 사용합니다.

## 요청자: 구매신청 보내기

### 1. 홈 → 구매신청

현장과 필요일을 고릅니다. 허용된 현장만 보입니다. 필요한 날짜를 모르면 나중에 구매 담당자와 확인하되, 긴급한 이유는 설명에 적습니다.

### 2. 무엇이 필요한가요?

예: “703K 화장실 배관 연결용 1/2인치 구리 엘보 20개, 금요일 필요.” 크기·재질·연결 방식·수량·용도를 아는 만큼 적습니다. 특정 모델이 필요하면 제조사와 모델을 함께 적습니다.

### 3. 자료 붙이기

사진 · 도면에서 사진이나 PDF 등을 고릅니다. 제품 링크에는 판매 페이지 주소를 넣습니다. 말로 입력을 누르면 짧게 녹음할 수 있습니다. 녹음은 최대 5분·15MB이며 끝나면 녹음 종료를 누릅니다.

### 4. 정리하기 또는 제품 찾기

정리하기는 입력 내용을 품목 목록으로 정리합니다. 제품 찾기는 후보를 보여줍니다. 후보의 제품 보기를 눌러 확인하고 이 제품 선택을 누릅니다. 직접 입력으로 곧바로 목록을 작성할 수도 있습니다.

### 5. 품목·규격·수량·단위 확인

자동 분석 결과도 보내기 전에 확인합니다. 개와 박스, ft와 m를 혼동하지 마세요. 여러 파일은 첫 파일만 분석하며 모든 파일은 요청에 첨부됩니다. 도면의 불명확한 치수·축척·부속 수량은 확인 없이 확정하지 않습니다.

### 6. 요청 보내기

요청을 보냈습니다 표시를 확인합니다. 요청은 저장됐지만 첨부 전송이 실패했다면 같은 화면에서 다시 보내 첨부를 마칩니다. 업로드가 끝나기 전에는 화면을 닫지 마세요. 서버 접수된 분석은 앱을 닫아도 이어집니다.

## 요청자: 진행 상태와 추가 질문 확인

### 내 요청에서 한눈에 보기

개인앱 → 구매신청 아래의 내 요청에 품목·현장·필요일·도착예정일·상태가 나옵니다. 카드를 누르면 품목 상세와 처리 이력을 확인합니다. 새로고침으로 최신 상태를 가져옵니다.

### 요청됨 / 검토 중

요청이 접수되었거나 구매 담당자가 검토를 시작한 상태입니다. 아직 주문이 완료된 것은 아닙니다.

### 정보 필요 / 보류 / 품절

정보 필요이면 요청을 열어 추가 내용이나 사진을 넣고 보완해서 보내기를 누릅니다. 보류·품절이면 상세의 사유를 확인합니다. 요청자가 답변했다고 구매완료로 바뀌지는 않습니다.

### 일부 구매 / 구매완료

일부 구매는 전체 요청 중 일부 수량만 주문한 상태입니다. 구매완료는 주문을 기록한 상태이며, 실제 현장 도착·검수까지 끝났다는 뜻은 아닙니다.

### 일부 입고 / 입고완료 / 취소

실제 확인된 입고 수량에 따라 표시됩니다. 취소는 구매 담당자가 기록합니다. 이미 주문한 물건은 판매처의 주문 취소 확인이 먼저 필요합니다.

### 알림은 어디서 보나요?

구매 담당자가 상태나 배송일을 바꾸면 선택한 내용으로 앱 활동함에 안내가 남습니다. 휴대폰 푸시를 허용한 기기에는 추가 알림을 시도합니다. 푸시가 꺼져 있어도 내 요청에서 확인할 수 있습니다. 문자·카톡 자동 발송 기능은 아닙니다.

## 구매 담당자: 최소 입력으로 처리하기

### 1. 자재·장비 → 구매요청

현장·상태 필터와 품목·요청자 검색으로 처리할 요청을 찾습니다. 처리 또는 품목을 누르면 사진·규격·수량·이력이 열립니다.

### 2. 검토 시작 / 정보 요청

검토 시작을 누릅니다. 규격이나 사진이 부족하면 정보 요청에서 사유를 고르고 적용합니다. 안내문을 매번 새로 타이핑할 필요가 없습니다.

### 3. 보류 / 품절 / 배송일

보류·품절은 사유 버튼을 선택하고 적용합니다. 배송일은 도착 예정일을 고릅니다. 미정이면 비워둡니다. 저장한 사실로 요청자 안내가 만들어집니다. 같은 내용을 반복 저장하면 알림을 중복 생성하지 않습니다.

### 4. 판매 사이트에서 직접 구매

제품 링크를 열어 판매처의 규격·재고·가격·배송일을 확인하고 구매 담당자가 주문합니다. 판매 사이트를 여는 것만으로 ERP가 구매완료 처리하지 않습니다.

### 5. 구매완료 기록

구매완료에서 주문서·영수증을 붙입니다. 서류 읽기를 사용하면 주문정보 입력을 줄일 수 있습니다. 주문정보 확인에서 구매처·주문번호·금액·통화·도착 예정일과 이번 주문 수량을 확인합니다.

### 6. 구매완료 · 자동안내

실제로 주문한 수량만 입력하고 저장합니다. 주문하지 않은 품목은 0으로 둡니다. 일부 주문이면 남은 수량이 유지됩니다. 다음 주문에는 그 주문의 증빙을 새로 붙입니다. 주문메일·쇼핑몰 결제를 자동 감시하는 기능은 포함하지 않습니다.

## 입고 확인과 연결 해제

### 1. 현장 도착 후 수량 확인

현장 수령자가 기존 자재 입고 화면에서 실제 물건과 수량을 확인하고 입고 기록을 확정합니다. 택배의 배송완료 표시만으로 ERP 입고를 확정하지 않습니다.

### 2. 구매요청과 입고 연결

구매 담당자는 요청을 열어 입고 연결을 누릅니다. 확정된 입고 기록을 고르고 요청 품목에 해당 입고 품목과 실제 수량을 연결합니다.

### 3. 잔량 확인

한 번에 다 오지 않았다면 실제 도착분만 연결합니다. 남은 수량은 다음 입고에 연결합니다. 중복 연결·초과 수량·단위 불일치는 차단됩니다. 이 동작으로 새 경비가 자동 생성되지는 않습니다.

### 휴대폰을 바꾸거나 분실했다면

새 휴대폰에서는 Google 또는 이메일·비밀번호로 로그인합니다. 권한 취소·계정 중지 역시 다음 서버 요청부터 적용됩니다.

### 앱을 닫기와 로그아웃은 다릅니다

앱을 닫는 것은 로그아웃이 아닙니다. 로그아웃하거나 로그인 정보가 만료되면 Google 또는 이메일·비밀번호로 다시 로그인합니다. 브라우저의 개인정보 보호 모드나 쿠키 자동삭제 설정은 연결 유지에 적합하지 않습니다.

### 홈 화면에 놓기

휴대폰 브라우저의 홈 화면에 추가 또는 앱 설치 메뉴를 사용하면 다음부터 아이콘으로 열 수 있습니다. 카메라로 연결한 브라우저와 홈 화면 앱의 저장공간이 분리되는 기기라면 새로 열린 앱에서 한 번 더 연결합니다.

## 막혔을 때 바로 확인할 것

### 구매신청이 안 보입니다

본인 계정인지 확인합니다. 수퍼관리자는 기본 표시됩니다. 다른 관리자는 계정·권한에서 개인앱 구매신청이 허용되어야 합니다. 새로고침 후 확인하고, 다른 사람의 계정으로 QR을 발급하지 않았는지 점검합니다.

### QR 목록에 사람이 없습니다

활성 상태의 내부 관리자이고 구매신청 또는 구매처리 권한이 있는지 확인합니다. 일반 작업자·반장·원청·열람 계정은 이 관리자 구매앱 연결 대상이 아닙니다. QR은 권한을 새로 부여하지 않습니다.

### QR 발급에 재로그인이 필요합니다

수퍼관리자라도 오래된 로그인이나 간편 출퇴근 입장만으로는 발급할 수 없습니다. 정식 로그인 후 첫 개인 QR을 발급합니다. 연결된 수퍼관리자 개인앱에서는 이후 QR을 발급할 수 있습니다.

### 연결 QR이 만료되었거나 이미 사용되었습니다

수퍼관리자에게 새 QR을 받습니다. 최초 연결이 이미 끝났다면 QR을 다시 찍지 말고 개인앱 주소나 홈 화면 아이콘을 엽니다.

### 분석·녹음·업로드가 실패했습니다

마이크 권한과 파일 크기·형식을 확인합니다. 분석을 기다리지 않고 직접 입력으로 요청할 수 있습니다. 이미 저장된 요청이 있는지 내 요청을 먼저 확인해 중복 요청을 피합니다.

### ERP 본화면 또는 구매처리를 열고 싶습니다

관리자는 개인앱 위의 ERP 로그인 또는 ERP 기본 주소로 접속합니다. 개인앱 인증만 있는 경우 로그인 화면이 열리며, 비밀번호·Google 인증 후 ERP 본화면으로 이동합니다. 개인앱 연결은 유지됩니다. 주문 처리는 구매 담당 권한이 있어야 합니다.

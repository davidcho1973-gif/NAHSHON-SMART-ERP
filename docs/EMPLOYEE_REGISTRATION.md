# 직원 등록 — 공용 링크

직원과 관리자 모두 `/join?lang=ko` 링크를 사용합니다. 첫 항목에서 ERP에 등록된 활성 현장의 코드·이름을 선택합니다. 지역명으로 새 현장을 만들지 않으며 현장명 변경도 목록에 반영됩니다. 인원 화면의 **직원 QR 등록**에서 공용 링크를 복사합니다. 기존 `/join/{site}`, `/join/w/{site}`, `/join/m/{site}`는 해당 현장이 미리 선택된 같은 양식을 표시하며 다른 등록 현장으로 변경할 수 있습니다.

- 총괄관리자는 `Global — 전체 현장 · 총괄관리`와 `총괄관리자` 직책을 선택합니다. Global은 실제 현장 레코드가 아닌 등록 범위이며, 기존 직원의 배정은 관리자가 변경합니다.
- Global 신청은 ERP 계정이나 전체 현장 권한을 자동 부여하지 않습니다. 담당자가 본인과 업무 범위를 확인합니다. 출퇴근을 사용하는 직원은 실제 근무 현장에 배정해야 합니다.
- 공정은 펼쳐지는 선택 메뉴에서 고릅니다. 현장을 고르거나 변경하면 해당 현장의 현재 공정표(WBS) 공정명을 불러옵니다. 공정표가 없거나 현장 미선택·Global이면 기본 직군을 표시합니다. ‘공무지원’은 항상 포함됩니다.
- 목록의 공정을 선택하면 별도 입력 칸 없이 선택한 공정이 저장됩니다. **목록에 없음 · 직접 입력**을 선택할 때만 **공정명 직접 입력** 칸이 나타납니다(필수·최대 60자). 수기 입력 중에는 글자를 지우거나 기존 공정명과 같아져도 칸이 사라지지 않습니다. 목록 조회 실패 시에도 수기 입력을 선택할 수 있습니다. 등록한 공정명은 직원 정보에 저장하며 공정표 작업이나 예산 항목을 자동 생성하지 않습니다.

- 공통: 이름, 소속회사, 공정, 직책, 전화번호를 작성합니다.
- 작업자: 이메일은 선택입니다. 회사 분류로 직접/간접 고용을 정하며, 미분류 회사만 소속 구분을 추가로 묻습니다.
- 반장, 기사·엔지니어, 소장, 안전, 사무관리: 이메일이 필수입니다. 기존 관리자 등록과 같이 관리직으로 기록됩니다.
- 인원 등록 및 게이트 출퇴근 등록과 ERP 접속 권한은 별개입니다. 공개 등록으로 계정을 만들거나 관리자 권한을 부여하지 않습니다. 권한 담당자는 등록자의 본인·직책·회사·현장을 확인하고 필요한 범위만 부여합니다.
- 팀 및 담당 반장 지정은 회사·팀 등록에서 확인합니다. 직책을 반장으로 선택하는 것만으로 특정 팀을 관리할 권한이 생기지 않습니다.

나손 직원 등록 공용 링크: https://nahshon-smart-erp-nahshon-mep-hntasf.laravel.cloud/join?lang=ko

등록 완료 후 **직원 앱 열기**를 누르면 `/attendance-app`으로 이동합니다. 현장/Global, 작업자/관리자, 재등록 모두 같습니다. 완료 내역·다음 사람 등록·W-9 링크를 확인할 수 있도록 자동 이동은 하지 않습니다. 이미 설치된 출퇴근 화면에서 등록했어도 직원 앱 버튼은 표시됩니다.

처음 이용하는 직원은 관리자가 본인 확인 후 직원과 로그인 계정을 연결하고 로그인 방법을 안내해야 합니다. 계정이 있는 직원은 로그인 후 앱을 사용하며, PIN 대상 직원은 관리자가 발급한 본인용 설정 링크로 PIN을 정합니다. 공개 등록만으로 로그인 권한이 생기지 않습니다. 다른 사람을 대신 등록한 폰에서는 앱이 현재 로그인한 사람의 계정을 사용하므로 새 직원은 본인 폰에서 로그인합니다.

앱 설치는 직원 앱의 **나 → 홈 화면에 추가**에서 진행합니다. 예전 `/gate/{site}?install=1` 링크도 직원 앱으로 이동합니다. 기존 현장 출퇴근 아이콘은 자동으로 교체되지 않으므로 새 직원 앱을 설치한 후 기존 아이콘을 정리합니다. 게이트의 설치 권유는 **직원 앱 열기** 링크로 바꿨으며 현장 QR의 출퇴근 처리 기능은 유지합니다.

출퇴근은 기존 `/gate/{site}/qr` 포스터 한 장을 작업자·관리자가 함께 사용합니다. 같은 QR에서 출근·퇴근을 처리합니다. 실제 현장 기록을 구분하기 위해 현장별 포스터는 유지하며 Global 출퇴근 현장을 만들지 않습니다.

가입 이력이 없는 사람으로 서버 테스트를 수행하며, 실서비스에 가짜 직원·출퇴근·알림 발송 기록을 만들지 않습니다.

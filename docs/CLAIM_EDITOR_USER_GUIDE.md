# 기성 편집 사용법

## 시작
ERP에서 현장 선택 → 공정 관리 → 공정별 도면 → 계약의 **기성 편집**을 누릅니다. 계약 공정이 있어야 사용할 수 있습니다. 계약 편집 권한을 가진 담당자가 기록·조건을 저장하며, 열람 권한만으로 확정할 수 없습니다.

왼쪽에서 공정을 고르면 가운데 도면·산출표, 오른쪽 작업 기록과 증빙이 열립니다. **미배정 확인액은 담당자가 확인했지만 회차에 아직 배정하지 않은 금액**입니다. 필수자료와 계약 조건을 모두 충족해야 제출할 수 있습니다.

## 기록
1. 작업일·위치를 확인합니다.
2. 산출 행에 위치, 길이, 높이, 개수, 공제를 입력합니다. `길이 × 높이 × 개수 − 공제`로 서버에서 다시 계산합니다. 산출 행이 없으면 직접 수량을 씁니다. 계약 단위에 맞춰 입력합니다.
3. 기존 자료를 검색해 누르거나 연결 영역으로 끌어옵니다. 다른 프로젝트·개인 문서는 연결되지 않습니다. ↑로 순서, ↻로 제출용 사진 방향, 설명 칸으로 위치·페이지를 정합니다. 원본 파일은 수정하지 않습니다.
4. **확인 대기로 기록**을 누릅니다. 저장만으로 시공 승인이나 기성 청구가 되지 않습니다. 기존 기록·확인에서 담당자가 증빙과 수량을 확인합니다.
5. 다음 작업은 **새 작업**을 누릅니다. 기록을 반복 클릭해도 같은 초안이 중복 생성되지 않습니다.

초안은 자동 저장됩니다. 저장되지 않음 안내가 나오면 창을 닫지 말고 다시 저장하세요. 다른 창과 충돌하면 최신 내용을 다시 열어 확인합니다. 초안 수정 이력에서 이전 내용을 복원할 수 있습니다. 이미 기록·배정한 내용은 초안 복원으로 덮어쓰지 않습니다.

반입과 설치는 별도입니다. 설치했다고 입고 수량이 자동으로 생기지 않습니다. 입고 송장과 실제 반입 수량을 따로 연결합니다.

## 도면과 AI
DWG/DXF 원본을 수정할 때는 **CAD 편집 · 기성 증빙 연결**을 누릅니다. 현재 기성 초안을 저장한 뒤 편집기가 같은 화면 안에 열립니다. 해당 현장의 CAD 도면을 불러와 수정·저장하고 **기성 증빙에 연결**을 누르면 정확한 저장 개정이 선택한 기성 줄의 초안에 붙습니다. 닫으면 기존 기성 화면으로 돌아옵니다. 연결 후 도면을 다시 수정해도 이전 증빙은 바뀌지 않습니다. CAD 수정과 증빙 연결만으로 수량·금액이 확정되지는 않습니다. 지원하는 편집 도구와 파일 제한은 [CAD 편집 사용법](CAD_EDITOR.md)을 참고하세요.

**도면 크게 열기·표시**에서 선·영역·화살표·메모를 그립니다. 목록의 ↔는 위치/크기, ⧉는 복사, ×는 삭제입니다. 실행 취소와 다시 실행을 지원합니다. 숫자는 메모로 표시합니다. 축척을 확인한 도면만 길이·면적을 가져옵니다. 도면 면적 자체는 실제 시공 완료 증명이 아닙니다.

영역을 그린 뒤 **선택 영역 AI 질문**에 질문합니다. AI의 답변·주의사항·수량 제안을 확인하고 **적용**하면 초안에 반영됩니다. 되돌리기로 취소할 수 있습니다. 읽을 수 없는 치수는 확인 후 입력하며, AI가 시공 승인이나 제출을 대신하지 않습니다. 도면의 표시를 적용하면 원본과 별도로 표시 이미지가 저장되어 증빙에 연결됩니다.

## 필수자료와 일괄 수정
공정 필수자료 설정에서 계약상 요구되는 자료 종류·단계·건수를 지정하고 저장합니다. 지정된 검측서 등이 없으면 확인과 회차 준비가 차단됩니다. 조건 변경 이력은 보존됩니다. 같은 자료를 여러 번 붙여 필수 건수를 채울 수 없습니다.

작업 이력에서 확인 대기 기록을 선택해 작업일·위치를 한 번에 바꿀 수 있습니다. 확인 완료·청구 배정 기록은 변경되지 않습니다. 수량이나 증빙의 정정은 기존 기록·확인에서 검토 상태를 확인한 뒤 처리합니다.

## 기성 제출 묶음
1. 마감일을 선택하고 **이번 회차 준비**를 누릅니다.
2. 확인된 실적 중 미배정 수량만 기존 기성 계산 규칙으로 가져옵니다. 이전 청구와 중복되거나 계약 조건이 맞지 않으면 중단합니다.
3. 표시되는 필수자료를 기성 청구·수금의 제출 서류 화면에서 보완합니다.
4. **원청 엑셀 + 증빙 묶음 생성**을 누르고 다운로드합니다.

ZIP에는 지원되는 원청 원본 양식의 엑셀, 인쇄 가능한 수량·사진·증빙 보고서(`quantity-and-evidence.html`), 원본 증빙, 목차/검증 manifest가 들어갑니다. HTML을 ZIP 밖에 따로 꺼내지 말고 폴더 전체를 압축 해제해 열면 사진과 원본 링크가 유지됩니다. 브라우저 인쇄로 PDF로 저장할 수 있습니다. 제출본은 버전별로 보관됩니다.

지원하지 않는 원청 엑셀 양식, 누락 자료, 변경된 원본, 미확인 실적은 자동 성공 처리하지 않습니다. 생성된 자료를 검토한 뒤 기존 제출 절차로 확정합니다.

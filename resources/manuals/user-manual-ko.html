작업자 · 반장 · 인사 · 현장 · 회계 · 관리자를 위한 전체 메뉴 안내

ERP로 돌아가기출퇴근 앱

실제 메뉴와 코드 흐름을 기준으로 정리했습니다. 계정 권한에 따라 표시되는 메뉴와 버튼은 다릅니다. 외부 서비스 연결과 실제 전달 여부는 별도 확인 대상입니다.

검색 결과가 없습니다. 다른 메뉴 이름으로 검색하세요.

GUIDE 1 · 관리자 · 인사담당

처음 사용하는 날

기준정보를 먼저 연결하면 여러 메뉴에서 같은 내용을 반복 입력할 필요가 줄어듭니다.

  1. 조직 설정에서 회사 표시정보를 확인합니다. 회사·팀 등록 → 현장·프로젝트 순서로 실제 현장과 소속 팀을 정리합니다.
  2. 직원 등록·관리에서 소속을 확인하고, 작업자 간편등록은 인사 · 작업자 등록에서 처리합니다. 같은 사람을 여러 메뉴에서 중복 생성하지 않습니다.
  3. 계정·권한 관리에서 직책과 열람 범위를 별도로 확인합니다. 관리자 역할과 전체 현장 범위는 서로 다른 설정입니다.
  4. 급여를 사용할 직원은 급여·회계 담당자가 임금 프로필을 확인합니다. 현장에 배정했다고 시급이 자동 확정되는 것은 아닙니다.
  5. 프로젝트 공정표·거래처·계약·문서를 연결한 뒤, 실제 업무 한 건을 끝까지 따라가며 다음 메뉴에 나타나는지 확인합니다.
다음 업무와의 연결

회사 → 현장/프로젝트 → 팀/직원 → 출퇴근·공정·문서 → 재무/보고로 이어지는 업무 구조가 준비됩니다.

확인할 점 이 설명서는 현재 구현된 업무 경로 안내입니다. 외부 메일·문자·푸시의 실제 전달과 현장 GPS 성능은 별도 환경 확인이 필요합니다.

GUIDE 2 · 모든 사용자

직책별로 할 일

작업자는 출퇴근에, 반장은 현장 운영에, 인사는 직원 등록에 집중합니다.

  1. 작업자: 개인 앱을 활성화하고 본인 출퇴근 기록을 확인합니다. 다른 직원의 등록·계정 권한을 관리하지 않습니다.
  2. 작업반장: 배정된 팀의 인력·일정·일일 보고 업무를 처리합니다. 직원 등록 화면에서는 자기 팀 현황만 조회합니다. 등록 승인이나 확인 의견 입력은 없습니다.
  3. 인사담당: 작업자 등록, 본인 확인, 승인, 개인 활성화 QR 발급과 계정 상태를 관리합니다. 상위 관리자 계정을 수정·정지할 수 없습니다.
  4. 현장소장·안전담당: 허용된 현장 운영 또는 안전 업무를 처리합니다. 인사 등록 권한은 별개입니다.
  5. 급여·회계: 임금 프로필, 급여·정산, 경비 및 청구 업무를 담당합니다. 인사담당의 임금 프로필은 조회 권한입니다.
  6. 관리자·슈퍼관리자: 전반적인 운영을 관리합니다. 조직 설정 등 일부 기능은 슈퍼관리자 전용입니다. 원청·뷰어는 열람 역할입니다.
다음 업무와의 연결

담당 업무와 데이터 범위를 분리합니다. 메뉴 노출만으로 권한을 판단하지 않고 서버에서도 확인합니다.

확인할 점 현재 여러 업무는 인사담당에게도 재무 관리 권한을 허용합니다. 인사와 회계를 완전히 분리하려면 별도의 권한 정책 변경이 필요합니다.

GUIDE 3 · ERP 사용자

화면 이동과 공통 사용법

조회 조건을 먼저 맞춘 후 기록을 확인하면 다른 현장 자료를 잘못 수정하는 일을 줄일 수 있습니다.

  1. 상단 회사와 현장을 확인합니다. 목록에 자료가 없다면 날짜·상태·회사·현장 필터부터 점검합니다.
  2. 왼쪽 메뉴에서 업무를 선택합니다. 펼쳐진 하위 메뉴는 접을 수 있으며 화면 폭에 따라 모바일 메뉴가 표시됩니다.
  3. 목록에서 상세를 열고, 브라우저 뒤로 가기로 이전 화면으로 돌아갑니다. 작성 중인 내용은 저장 후 이동합니다.
  4. 저장은 완료 메시지와 새로고침 후 목록 반영을 함께 확인합니다. 오류가 뜨면 같은 버튼을 반복 누르기 전에 메시지를 읽습니다.
  5. 문서 파일 열기, 다운로드, 출력은 별도 화면 또는 탭으로 열릴 수 있습니다. 닫으면 원래 ERP 화면으로 돌아갑니다.
다음 업무와의 연결

조회 조건 → 목록 → 상세 → 저장 결과 확인이 공통 작업 순서입니다.

확인할 점 휴대폰에서는 작업자 앱 주소를 홈 화면에 추가합니다. ERP와 출퇴근 앱은 목적이 다른 화면입니다.

GUIDE 4 · 인사담당 · 관리자

인사 전용 작업자 등록

이메일이나 문자 인증 없이 이름·전화번호로 등록하고, 본인에게만 개인 앱을 연결합니다.

  1. 인사 · 작업자 등록 화면을 열어 이름·전화번호·소속 팀을 입력합니다. 국가번호와 기존 등록 여부를 확인합니다.
  2. 인사담당자가 실제 직원인지 확인한 후 승인합니다. 반장에게 등록 권한이나 승인 절차를 넘기지 않습니다.
  3. 직원 개인용 활성화 QR 또는 링크를 발급합니다. 15분 동안 유효하며 한 번 사용하면 다시 사용할 수 없습니다.
  4. 현장에서 직원 본인 휴대폰으로 QR을 스캔하고 직원이 PIN을 설정합니다. PIN은 직원이 직접 정하며 공용으로 배포하지 않습니다.
  5. 연결 후 출퇴근 앱을 홈 화면에 추가하고 직원 이름과 현장을 확인합니다. 기기 변경·링크 만료 시 인사가 새로 발급합니다.
다음 업무와의 연결

직원 정보와 로그인 계정이 연결됩니다. 팀 공용 가입 QR은 사용하지 않습니다.

확인할 점 이름·전화번호 입력은 본인 확인 완료를 뜻하지 않습니다. 개인 활성화 링크를 단체 채팅방에 올리지 않습니다. 반장은 현황 조회만 합니다.

GUIDE 5 · 작업자 · 반장

작업자 출퇴근 앱

본인 휴대폰에서 출근·퇴근을 기록하고 누락 여부를 확인합니다.

  1. 앱을 열어 본인 이름, 선택 현장, 현재 근무 상태를 확인합니다. 로그인 상태가 풀렸으면 등록된 기기에서 PIN으로 로그인합니다.
  2. 현장 안내에 따라 위치·카메라 권한을 허용하고 화면에 제시된 출근 방법을 사용합니다. 현장 QR은 개인 활성화 QR과 다른 용도입니다.
  3. 출근 버튼 처리 후 출근 시각이 표시되는지 확인합니다. 퇴근할 때도 상태가 바뀌었는지 확인합니다.
  4. 출퇴근 누락이나 잘못된 현장은 담당자에게 날짜·시각·현장을 전달해 정정받습니다. 잘못된 기록을 덮으려고 여러 번 찍지 않습니다.
  5. 휴대폰 교체·분실·PIN 문제는 인사담당에게 요청합니다. 일반 직원의 기본 사용 화면은 출퇴근 앱입니다.
  6. 하단 메뉴는 출퇴근·근무·나로 구성됩니다. 작업자 앱에는 시급·예상 급여·급여명세서를 표시하지 않습니다. 급여·정산은 권한이 있는 관리자가 ERP에서 처리합니다.
다음 업무와의 연결

출퇴근 기록이 인원·급여 검토의 근거가 됩니다. 승인 상태와 근로시간 정산은 별도 단계입니다.

확인할 점 GPS가 꺼져 있거나 현장 위치 설정이 잘못되면 실패할 수 있습니다. 위치 확인 실패를 임의로 우회하지 말고 현장 설정을 확인합니다.

GUIDE 6 · 현장 관리자

한 사람이 관리하는 하루 순서

모든 메뉴를 매일 열기보다 예외와 승인 대기 항목부터 처리합니다.

  1. 아침: 알림 → 공정 관리에서 오늘 작업·선행작업·납기 지연을 확인합니다. 인원에서 실제 투입 인력을 확인합니다.
  2. 오전: 문서함에 도착한 파일을 올리고 업로드 완료를 확인합니다. AI 분석 대기·실패는 별도로 확인합니다.
  3. 작업 중: 반장의 사진·실적·이슈를 현장 상황실과 일일 보고에서 검토합니다. 원청 관련 자료는 문서함에 보관하고 발송 결과는 서신 원장에서 확인합니다.
  4. 오후: 조달 입고와 영수증·문서에서 생성된 재무 대기 건을 원본과 대조합니다. 같은 거래가 두 경로로 올라왔는지 확인합니다.
  5. 마감: 미퇴근·인원 차이·미완료 작업을 정리하고 일일 마감을 처리합니다. 보고서 보관과 발송 상태는 각각 확인합니다.
  6. 주간: 공정 지연, 조달 ETA, 청구·수금, 계약 만료, 문서 분석 실패를 묶어서 점검합니다.
다음 업무와의 연결

반복 입력보다 누락·지연·오류·승인 대기를 중심으로 운영합니다.

확인할 점 AI 분석이나 자동 경비 생성은 담당자의 승인·실물 입고 확인을 대신하지 않습니다.

GUIDE 7 · 관리자 · 허용된 조회 사용자

대시보드

선택한 회사·현장의 요약 상태를 확인하는 출발 화면입니다.

  1. 회사·현장과 기준 날짜를 먼저 맞춥니다.
  2. 인원·공정·재무 요약 중 이상이 있는 항목의 상세 메뉴를 엽니다.
  3. 요약 수치가 예상과 다르면 상세 목록의 기간·상태·범위를 맞춰 비교합니다.
다음 업무와의 연결

각 상세 모듈의 자료를 요약해서 봅니다. 대시보드에서 원본 기록을 대체 입력하지 않습니다.

확인할 점 요약의 0은 데이터 없음 또는 필터 범위 차이일 수 있습니다. 실제 기록이 삭제되었다고 곧바로 판단하지 않습니다.

GUIDE 8 · 관리자 · 현장 운영자

AI 현장 지휘실

현장 정보와 위험·할 일을 요약해 우선순위를 잡습니다.

  1. 현장·프로젝트를 선택하고 표시된 기준 자료를 확인합니다.
  2. 요약에 나온 공정·문서·조달 항목을 원본 화면에서 엽니다.
  3. 날짜·금액·완료 여부가 원본과 맞는지 검토한 뒤 후속 업무를 처리합니다.
다음 업무와의 연결

요약에서 실제 업무 항목으로 이동합니다.

확인할 점 AI 제공자·키·분석 작업 상태에 따라 일부 결과가 제공되지 않을 수 있습니다. 요약을 승인 문서로 사용하지 않습니다.

GUIDE 9 · 모든 허용 사용자

알림

업무 지연·대기·요청을 모아서 확인합니다.

  1. 읽지 않은 알림과 긴급 항목부터 엽니다.
  2. 연결된 원본에서 처리한 뒤 상태를 확인합니다.
  3. 휴대폰 푸시가 필요하면 앱의 알림 허용을 선택하고 브라우저 설정도 확인합니다.
다음 업무와의 연결

알림은 업무 진입점이며 처리 결과는 원본 모듈에 남습니다.

확인할 점 ERP 안에서 알림이 보이는 것과 휴대폰·카카오·이메일로 전달되는 것은 별개입니다. 각 채널의 설정이 필요합니다.

GUIDE 10 · 현장 운영자 · 관리자

공정 관리

작업 단위별 일정·선행관계·실적을 관리합니다.

  1. 프로젝트와 현장을 선택합니다. 공정의 작업명·기간·담당·구역을 확인합니다.
  2. 일정 변경 시 선행작업 및 후속작업 영향을 함께 확인합니다. 동시에 가능한 작업만 병행합니다.
  3. 현장 실적과 완료 상태를 기록하고 사진·일일 보고를 근거로 남깁니다.
  4. 조달 탭에서 발주성 공정의 도착예정일과 필요일을 확인합니다.
다음 업무와의 연결

확인할 점 작업을 완료 표시했다고 발주·입고·대금 지급이 모두 완료되는 것은 아닙니다. 공정과 구매 상태를 각각 확인합니다.

GUIDE 11 · 구매 담당 · 현장 관리자

공정 관리 안의 조달 관리

  4. 실물 수량과 납품서를 확인한 뒤 입고완료로 바꿉니다. 금액이 있는 입고완료 건은 재무 대기 경비로 이어집니다.
  5. 회계 연결 경고가 뜨면 원래 조달 저장 여부를 확인하고, 경고 원인 해결 후 해당 건을 다시 저장해 연결을 확인합니다.
다음 업무와의 연결

GUIDE 25 · 현장·자재 담당 · 관리자

자재 입고

현장에 실제로 도착한 자재를 수량과 함께 적습니다. 공정표(WBS)에 그 자재 줄이 없어도 기록할 수 있습니다.

  1. 사진으로 입고를 누르고 납품서(패킹리스트·인보이스)를 찍습니다. AI가 공급처·납품서 번호·품목·수량을 읽어 «확인 대기» 한 장을 만듭니다.
  2. 화면에 뜬 품목·수량을 눈으로 확인하고 틀린 줄을 고칩니다. 품목은 한 줄에 하나씩 «품목명 | 수량 | 단위 | 단가 | 메모» 로 적습니다.
  3. 맞으면 확정을 누릅니다. 확정 전에는 «확인 대기» 로 남아 있습니다. 확정하면 단가가 적힌 줄의 합이 회계 대기(재무 › 경비, 승인 전)로 자동으로 넘어갑니다. 단가가 하나도 없으면 «모름» 이라 넘기지 않고, 확정을 풀면 회계 대기에서 빠집니다(이미 승인된 건은 남습니다).
  4. 납품서가 없거나 AI가 못 읽으면 직접 입력으로 현장·입고일·품목·수량만 적어도 됩니다.
다음 업무와의 연결

공급처는 거래처 대장에, 품목명이 품목 마스터와 같으면 그 품목에 연결됩니다. 확정한 입고 금액은 회계 대기로 가서 재무 담당이 승인하면 원가가 됩니다. 같은 PO가 조달 관리에서 이미 회계 대기로 갔으면 두 번 넣지 않습니다. 찍은 납품서 원본은 근거로 남아 나중에 수량을 설명할 수 있습니다.

확인할 점 AI가 읽은 수량은 사람이 확정하기 전까지 장부가 아닙니다. 번진 글씨의 10이 100으로 읽히는 일이 있으므로 확정 전에 수량을 반드시 눈으로 봅니다. 확정한 뒤에는 수정·삭제가 막히며, 고치려면 «확정 해제» 를 먼저 누릅니다. 공정 관리 안의 조달 관리(GUIDE 11)는 «언제까지 와야 하는가» 를, 이 화면은 «무엇이 실제로 왔는가» 를 봅니다.

  5. 공종 머리에 계획 인원 옆에 오늘 출근 인원이 같이 나옵니다(출퇴근 기록에서 자동). 계획과 현실이 나란히 보입니다.
  6. 다음 주 월요일, 「지난주 못한 N줄 이월」 을 누르면 못 끝낸 줄이 넘어옵니다. 같은 일이 여러 주째 넘어오면 그 일이 막혀 있다는 뜻입니다.
  7. 「3주 나란히」 를 누르면 지난주 · 이번 주 · 다음 주가 옆에 놓입니다(↩ 는 넘어온 줄, 🤖 는 상황실 글로 바뀐 줄). 보기용입니다 — 줄을 누르면 고치는 창이 열리고, 「이 주 보기」 로 그 주에 들어가면 상태 버튼이 나옵니다. 「+ 줄」 로 다음 주에 미리 적을 수 있습니다.
다음 업무와의 연결

줄에 정식 공정표 코드를 붙여 두면(선택) 그 줄이 완료될 때 공정표의 그 작업도 완료로 넘어가 진척률이 올라갑니다. 붙이지 않으면 작업판은 작업판대로, 공정표는 공정표대로 있습니다 — 둘이 다른 것은 정상입니다.

확인할 점 공종 목록은 도면에서 분석한 공정표의 공종 + 직원 공종(일일보고)입니다 — 「전기」 와 「전기/배관」 이 따로 생기면 두 공종이 됩니다. 비서가 인원을 안 적었으면 말에 인원이 없었던 것입니다 — 추측해서 채우지 않습니다. 정식 공정표를 고치는 화면이 아닙니다; 원청 보고용 날짜·순서는 공정 관리에서 다룹니다.

GUIDE 50 · 현장소장 · 관리자

공정별 도면

원청 계약 기성표의 공정마다 그 일을 그 위에 그리고 적을 도면을 고릅니다. 공정 관리 아래 「공정별 도면」 에 있습니다.

  1. 도면 올리기로 도면 PDF 를 올립니다. 파일은 문서함에 들어가고, 이 화면이 한 쪽씩 읽습니다. 문서함에 이미 올린 도면은 화면을 여는 것만으로 읽기가 시작됩니다.
  2. 도면에 글자가 들어 있는 쪽은 그 글자를 그대로 씁니다. 사진으로 저장된 쪽은 네 조각으로 잘라 AI 가 글자를 읽어 붙입니다(「사진 → AI 판독」 표시). 읽는 동안 이 화면을 닫지 마세요 — 쪽을 보내는 일은 이 화면이 합니다.
  3. 공정 카드의 도면 고르기에서 도면을 체크합니다. 평면을 먼저, 일람표·상세는 참고로 고릅니다. 아직 올리지 않은 도면은 번호만 적어 두면 파일이 읽힐 때 저절로 붙습니다.
  4. 도면을 누르면 크게 보이고, AI 가 읽은 글자를 확인할 수 있습니다. 번호나 제목이 틀리면 고쳐 저장합니다 — 고친 번호는 다시 읽어도 바뀌지 않습니다.
다음 업무와의 연결

여기서 고른 도면이 공정별로 도면 위에 그리고 멘트를 적는 바탕이 됩니다. 선택은 도면 번호로 저장하므로 개정판을 올려도 선택이 유지됩니다. 703K 는 계약서의 공정 24개와 공정별 도면이 미리 골라져 있습니다.

확인할 점 도면 파일은 문서함에서 현장이 지정돼 있어야 이 화면에 나옵니다. 문서함이 도면으로 분류하지 않은 PDF 는 「문서함의 다른 PDF 를 도면으로 쓰기」 로 골라 읽습니다. 사진 쪽 판독은 쪽마다 수십 초 걸립니다.

계약서 올리기 — 기성이 곧 공정

원청 계약 기성표(엑셀)를 계약서 올리기로 올리면 계약서의 줄이 공정 카드 아래에 붙습니다. 공정마다 확인된 기성 ÷ 계약 금액이 진행률입니다.

  1. 파일을 고르면 무엇을 읽었는지 먼저 보여 줍니다 — 계약 합계, 줄 수, 공정별 줄·소계. 섹션마다 줄 금액의 합이 계약서 소계와 맞지 않으면 올리지 않습니다.
  2. 어느 계약의 줄인지 고릅니다. 금액이 같은 수주 계약이 있으면 미리 골라져 있고, 없으면 «새 수주 계약 만들기»로 계약서 금액 그대로 만듭니다. 유보율·선급금 조건은 계약 화면에서 채웁니다.
  3. «원청과 맺은 계약 내역입니다» 를 체크하고 줄 올리기를 누릅니다. 줄의 수량·단가가 계약 조건으로 확정됩니다. 이후 계약 변경은 RFI 로만 합니다 — 같은 번호 줄의 수량·단가가 다른 계약서를 다시 올리면 덮지 않고 멈춥니다.
  4. 자재 단가와 노무 단가가 둘 다 있는 줄은 반입(자재 단가만큼)과 설치(나머지)로 나눠 받습니다. 자재가 들어오면 반입, 설치하면 설치로 기록합니다. 둘 다 확인되면 줄 전액입니다.
  5. 공정 카드의 줄 보기에서 줄마다 진행률을 보고, 기록·확인으로 기성 근거 대장의 그 줄을 열어 수량과 사진·문서 근거를 연결합니다. 사람이 확인한 수량만 진행률과 기성에 들어갑니다.

줄마다 기록하기

  1. 공정 카드의 줄 펼치기를 누르면 그 공정의 계약 줄이 바로 보입니다. 703K 는 계약서 350줄이 이미 공정마다 들어가 있습니다.
  2. 줄의 기록을 누르고 반입이나 설치, 수량, 위치, 사진·송장을 넣습니다. 설치를 기록하면 아직 적히지 않은 반입도 같은 수량으로 함께 적습니다.
  3. 기록은 확인 대기로 들어갑니다. 담당자가 확인을 눌러 사진을 보고 수량을 확인하면 진행률과 기성에 들어갑니다.

도면 위 표시

  1. 줄의 기록 창에서 도면에서 찍기를 누르면 그 공정에 고른 도면이 크게 열립니다. 위치 칸에 방 이름을 적었으면 도면에서 그 글자를 찾아 보여 줍니다.
  2. 벽·배관·전선은 선, 바닥·천장은 영역, 기구는 점이 먼저 골라져 있습니다. 차례로 누르고 완료를 누르면 기록과 함께 저장됩니다.
  3. 공정 카드의 도면을 누르면 표시가 모두 얹힌 도면이 열립니다. 색은 저절로 바뀝니다. 주황은 확인 대기, 초록은 확인됨, 파랑은 반입 자재 확인, 회색 점선은 계획, 보라는 메모입니다.
  4. 표시를 누르면 수량·날짜·위치·사진이 뜹니다. 손가락 두 개나 마우스 휠로 확대하고, 끌어서 이동합니다. 관리자는 아래 도구로 점·선·영역·메모를 더할 수 있습니다.

도면으로 재고, 적고, 청구하기

  1. 도면에서 재기: 도면 위쪽의 📐 축척 버튼이 도면 글자에서 축척(예: 1/4" = 1'-0")을 읽어 둡니다. 없으면 «아는 치수로 맞추기»로 치수선 양 끝을 찍고 실제 길이를 적습니다. 그다음부터 선은 길이, 영역은 면적이 되어 기록 수량에 저절로 들어갑니다. 면적 단위 벽을 선으로 그리면 높이를 한 번 묻고, 이 기기가 기억합니다.
  2. 여러 개 그리고 설명 붙이기: 기록 창의 «도면 열어 표시·설명»에서 선·영역·점·메모를 여러 개 그리고, 도면에 붙일 설명을 적거나 붙여넣은 뒤 «기록 창으로»를 누릅니다. 기록할 때 함께 저장됩니다.
  3. 반듯한 선: 거의 가로·세로인 선은 저절로 반듯해집니다. 비스듬히 그리려면 Alt 를 누른 채 찍습니다. 영역은 첫 점 근처를 누르면 닫힙니다.
  4. 1차·2차 기성 색: 🎨 버튼으로 색 기준을 바꿉니다. «기성 회차별»이면 1차·2차·3차 기성이 서로 다른 색으로, 확인됐지만 아직 청구 안 한 일은 «다음 기성 대상» 초록으로 보입니다. 청구된 표시가 있으면 처음부터 이 색으로 열립니다.
  5. 남은 일: 목록 아래 «이 도면에 표시 안 된 줄»을 누르면 바로 그 줄을 찍습니다.
  6. 청구 증거로 내보내기: 이번 달·지난 달을 고르고 «내보내기»를 누르면 범례·축척·날짜가 들어간 도면 그림이 내려받아집니다.
  7. 계약 수량 초과: 누적 수량이 계약을 넘으면 기록 창이 빨간 글씨로 RFI 가 필요하다고 알려 줍니다.

원청 청구서 엑셀

  1. 공정별 도면 위쪽 기성 칸의 원청 청구서 엑셀을 누릅니다.
  2. 이번 달 마감일을 고르고 초안 만들기를 누르면, 마감일까지 확인된 수량 중 아직 청구하지 않은 것이 이번 회차에 들어갑니다.
  3. 미리보기에서 금회 공사 금액, 반입 자재, RFI 변경 공사, 유보금, 받을 돈을 확인하고 엑셀 내려받기를 누릅니다.
  4. 파일은 원청이 준 기성표 양식 그대로입니다. 줄마다 전회·금회 수량이 채워지고, 오른쪽에 반입 자재(미설치) 칸이 붙고, 표지의 OTHERS 줄이 MATERIALS STORED 가 됩니다. 승인된 RFI 작업은 4_RFI CHANGE ORDERS 시트로 붙어 표지 V/O 줄에 잡힙니다.

확인할 점 원청 양식의 소계 수식 6칸은 범위가 틀려 2차부터 금액이 부풀기 때문에 바로잡아 냅니다(미리보기에 적힘). 선급금 상환 방식은 계약서에 없어 비워 둡니다. 설치가 반입보다 많은 줄이 있으면 먼저 반입 기록을 더하라고 멈춥니다. 원청 양식은 천 달러 단위로 절사하므로 ERP 초안 금액과 조금 다릅니다.

작업 추가 RFI · 감액

  1. 공정 카드의 작업 추가 RFI를 누릅니다. 추가는 작업명·단위·수량·자재 단가·노무 단가를 적고, 감액은 줄일 계약 줄과 수량을 고릅니다. RFI 문서가 있으면 붙입니다.
  2. 제출하면 승인 대기로 적힙니다. 추가 줄에 현장 기록과 사진은 미리 모을 수 있지만, 원청 승인 전에는 청구에 들어가지 않습니다.
  3. 원청이 승인하면 승인을 누르고 승인 메일·공문을 붙입니다. 그 순간 계약 금액이 바뀌고 줄이 청구 대상이 됩니다. 감액은 이때 기존 줄의 수량이 줄고, 원래 수량은 기록으로 남습니다.
  4. 반려나 취소를 누르면 현장 기록이 없는 추가 줄은 지워집니다. 이미 확인된 수량보다 적게 감액할 수는 없습니다.

확인할 점 계약서의 천 달러 절사(줄 합계와 계약 금액의 차이)는 화면 위쪽에 따로 보입니다. «설치가 반입보다 많음» 이 뜨면 반입 기록이 빠져 그 자재값을 못 받고 있는 것입니다. 금액은 기성 권한(관리자·현장소장·급여 담당)이 있는 사람에게만 보입니다.

  4. 같은 영수증을 문서함에도 올렸다면 회계 담당자가 중복 여부를 확인하도록 알립니다.
다음 업무와의 연결

모바일 제출 → 경비 대기 → 회계 검토로 이어집니다.

확인할 점 영수증 업로드와 지출 승인은 다릅니다. 원본이 잘리지 않도록 촬영합니다.

GUIDE 45 · 모든 사용자

오류가 생겼을 때

반복 입력으로 중복을 만들기 전에 문제를 구분합니다.

  1. 화면이 비어 있음: 회사·현장·날짜·상태 필터, 로그인 계정의 권한을 확인합니다.
  2. 버튼 실패: 오류 문구·시간·메뉴·대상 번호를 기록합니다. 다시 조회해서 실제 저장 여부부터 확인합니다.
  3. AI가 계속 대기: 업로드 완료 여부와 서버 큐 상태를 관리자에게 확인합니다. 실패 건은 원본 파일·비밀키 설정·서비스 할당량·지원 형식을 점검합니다.
  4. 재무 연동 경고: 원본 조달 저장을 확인하고 연결 오류를 해결한 뒤 해당 건을 다시 저장합니다. 같은 경비를 수동으로 추가하기 전 기존 건을 찾습니다.
  5. 출퇴근 실패: 본인 계정·현장·위치 권한·현장 좌표·기기 활성화를 확인합니다.
  6. 알림 미수신: ERP 안의 알림과 외부 발송 상태를 따로 확인합니다. 휴대폰 알림 차단 여부도 확인합니다.
다음 업무와의 연결

담당자에게 전달할 최소 정보: 화면 이름 / 날짜·시각 / 대상 번호 / 오류 문구 / 수행한 작업.

확인할 점 문제 화면을 공유할 때 직원 개인정보·계좌·비밀번호·활성화 QR을 노출하지 않습니다.

GUIDE 47 · 관리자 · 현장소장

공정미팅 · 회의에서 ERP 반영

15–20분 회의를 기록하고, 필요한 확인을 한 화면에서 처리합니다.

  1. 현장 상황실 → 공정미팅에서 현장·회의일·참석자를 입력합니다. 참석자에게 녹음을 알리고 녹음하거나 기존 파일을 선택합니다. 최대 30분·64MB입니다.
  2. 녹음 중에는 화면을 유지합니다. 업로드하고 분석 시작을 누른 뒤 서버 저장 완료가 표시되면 앱을 닫아도 됩니다. 실패한 업로드는 같은 파일로 이어 올립니다.
  3. 두 음성인식 결과와 기존 BOQ·발주·공정 자료를 대조합니다. “방문 언제 입고되는지 확인”은 기존 납기 조회와 내부 확인 업무로 연결되며 발주나 입고 완료로 바뀌지 않습니다.
  4. 확인할 사항에서 근거 듣기와 두 전사를 확인합니다. 수정·대상 선택 → 확인 후 반영 순서로 처리합니다. 대상 정보가 그 사이 바뀌면 최신 값을 다시 확인합니다.
  5. 명확한 조회·내부 요청은 자동 처리하고, 진척·계획·조달·검사 일정·실제 출역은 확인 후 반영합니다. 조건부 작업, 복수 후보, 숫자 불일치는 보류합니다.
  6. 결과는 기존 공정·조달·상황실 할 일 및 회의 날짜의 일일 마감 집계에 연결됩니다. 알림센터에서 처리 결과를 열 수 있습니다. 일일 마감 확정과 외부 발송은 별도입니다.
  7. 반영 취소는 이후 변경이 없을 때 가능합니다. 다른 사람이 처리했거나 후속 공정까지 이동했다면 원래 업무 화면에서 정정합니다.
연결 전 확인

Gemini와 ElevenLabs 키·모델 접근권한, 영구 저장소, 서버 작업 프로세스가 필요합니다. 키 설정됨 표시는 실제 음성인식 성공을 보장하지 않습니다. 실제 회의 샘플로 제품명·숫자·담당자·날짜·정정 인식을 확인하세요.

개인 근태·급여, 결제·승인, 메일·Slack 발송을 회의만으로 실행하지 않습니다. 공통/Global 미배정 자재 및 문서·이메일 본문 검색은 이번 연결 범위에 포함되지 않습니다.

회사 이메일 분석함

본인의 Outlook 메일과 첨부파일을 자동으로 읽고, 필요한 업무만 프로젝트 자료로 공유합니다.

  4. AI 질문은 현재 로그인 사용자가 원래 열람할 수 있는 문서만 검색합니다. 재무 자료는 기존 재무 권한을 그대로 적용합니다.
  5. 연결 카드에서 최근 동기화와 오류 상태를 확인합니다. 계정 변경이나 퇴사 시 연결 해제를 실행합니다.
